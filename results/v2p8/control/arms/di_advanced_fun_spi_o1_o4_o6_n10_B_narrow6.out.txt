Panel F2d (image reviewed) plots relative FWHM, Δσ/σ (%), vs. temperature for SC, PC, and HOC, each with two or more peak families. It confirms the stated numbers: SC's peaks (esp. (400), (224)) drop from ~100-110% to ~45-50% right at ~150 K, while (242) stays higher (~80%). PC's (242) peak spikes to ~260% near ~150 K before decaying; HOC's (004) peak rises to ~128% around 150-155 K. So all three phases show a distinct anomaly in peak width clustered in the same narrow window (~150-155 K).

What this supports: a structural transition (STR) occurs at essentially the same temperature (~150-155 K) across SC, PC, and HOC, so the transition itself is not confined to one phase. But the microstructural signature of that transition differs by phase/domain scale in the same direction as the earlier lattice-expansion result: SC (coarsest domains, smooth linear peak-shift) responds with peak sharpening (width drop), consistent with a coherent, single-step transition; PC (finest domains, most curvature/offset) and HOC (intermediate) instead show peak broadening (width spike), consistent with strain, phase coexistence, or heterogeneous lattice response during the transition. This reinforces, via a second independent XRD observable (width, not just position), the same domain-size/phase correspondence already established.

What it leaves open: still only three phase categories, so this is corroboration, not a dose-response test; width anomalies can arise from strain, peak overlap, or instrument/fit artifacts, not domain size alone; and domain size remains confounded with phase identity/composition as the true driver — this panel cannot isolate which one causes the differing width response.</message>
