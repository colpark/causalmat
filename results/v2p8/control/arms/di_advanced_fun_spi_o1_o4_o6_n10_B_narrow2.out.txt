Panel F2d plots relative FWHM (Δσ/σ, %, normalized to 700 K) vs. temperature for the same three phases. Near 150 K, the curves diverge sharply: SC's peak width drops from ~100% to ~50% (sharp narrowing at the transition), while PC's width rises to ~260% (driven by the 242 reflection) and HOC's rises to ~128% — both showing pronounced broadening instead of narrowing. Ordered by magnitude of broadening, PC (finest domains, ~0.1 μm) > HOC (~10–100 μm) > SC (~1e2–1e3 μm, which actually narrows), which is the inverse order of domain coarseness recorded in Observation A.

This is a fourth, independent XRD observable (peak width, not peak position) that shows the same phase-ordered pattern already seen for expansion-curve smoothness: the coarse-domain phase (SC) behaves distinctly and more "simply" at the transition (narrowing), while the finer-domain phases (PC, HOC) show larger, more anomalous responses (broadening), with PC's response the largest. It strengthens the three-point correspondence between domain scale and transition-related XRD anomalies by adding a second, independent metric that tracks the same ordering.

It leaves open exactly what the prior result left open: still only three phases, so this is a three-point correspondence, not a dose-response curve; peak width and peak position are different XRD-derived quantities and neither is a direct measurement of domain size, so the link remains cross-observable/cross-technique, not a measured causal effect; and domain size stays confounded with phase identity/composition, so this measurement cannot isolate domain size as the driver of either the broadening or the narrowing behavior.</message>
