MatMech argument graphs

Each paper becomes one directed graph that follows its argument: hypothesis → selection → processing → structure → property → performance → discussion. Measurements sit in between as evidence nodes, and each figure-to-claim edge names the multimodal reasoning step it performs. Node types come from a shared vocabulary built by a saturation sweep: staff agents decomposed papers and a senior-investigator agent ruled on every new type.
