- Linked text (the paper's own sentences, as linked by the PDF parser): The detailed fabrication route of $\mathsf { S } { - } \mathsf { g } { - } \mathsf { C } _ { 3 } \mathsf { N } _ { 4 }$ -E is skillfully realized via carbonization, hot exfoliation, hydrothermal treatment and subsequent annealing process, as schematically illustrated in Fig. 1. A typical thermal polycondensation process of melamine takes place firstly, resulting in the formation of bulk ${ \tt g } – { \sf C } _ { 3 } \Nu _ { 4 }$ . After the hot exfoliation process, the bulk ${ \tt g } – { \sf C } _ { 3 } { \sf N } _ { 4 }$ is stripped into with smaller, thinner and wider spaced $\mathrm { g - C } _ { 3 } \mathrm { N } _ { 4 }$ -E, which is convenient for intercalation of liquid sulfur species (Fig. S1 in the Supporting Information). Subsequently, the $\mathrm { g - C _ { 3 } N _ { 4 } \mathrm { - E } }$ is subjected to a hydrothermal treatment with sulfur powder at high temperature to form $S @ \mathbf { g } _ { - }$ ${ \mathsf { C } } _ { 3 } { \mathsf { N } } _ { 4 }$ -E. Particularly, the added sulfur powder melts into liquid sulfur at high temperature, which is conducive to the full introduction of sulfur species. Moreover, the larger interlayer spacing of $\mathrm { g - C _ { 3 } N _ { 4 } } .$ - E also facilitates the full contact between the liquid sulfur and the sample. Finally, the $\mathsf { S } { - } \mathsf { g } { - } \mathsf { C } _ { 3 } \mathsf { N } _ { 4 }$ -E catalyst is obtained by the thermopyrolysis of ${ \sf S @ g - C _ { 3 } N _ { 4 } }$ -E under flowing $\Nu _ { 2 }$ atmosphere. Inimitably, the pyrolysis step can not only eliminate and remove excess sulfur species other than S dopants, but also can significantly increase the porosity of the catalyst since the self-gas foaming effect of sulfur vapor.
