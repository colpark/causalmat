- Linked text (the paper's own sentences, as linked by the PDF parser): Due to its low solubility, LiFSI does not dissolve in the pristine HFE solvent (Figure S1a, Supporting Information). To prepare the electrolyte, first LiFSI is completely dissolved in the IL $( \mathrm { [ P P _ { 1 3 } ] [ F S I ] } )$ , and then HFE is added into the solution. A transparent and clear electrolyte can be obtained at the IL/HFE molar ratio of 1:2 (Figure S1b, Supporting Information). At the IL/HFE ratio of 1:3, the electrolyte changes from transparent to opaque due to the precipitation of oversaturated Li salt (Figure S1c, Supporting Information). The viscosity and ionic conductivity of different electrolytes are shown in Figure 1a. To our best knowledge, viscosity greatly influences ion transport in the electrolyte and the ionic conductivity. Because of the low viscosity of the HFE, its addition to the pure ILE $2 . 1 \ \mathrm { M }$ LiFSI– $\mathrm { \cdot [ P P _ { 1 3 } ] [ F S I ] ) }$ significantly decreases the viscosity of the electrolytes and enhances the ionic conductivity. When the $\mathrm { I L } /$ HFE ratio is changed to 1:2, LHCE achieves the lowest viscosity of $6 . 8 \mathrm { \ m P a \ s }$ , which is comparable to $5 . 9 \mathrm { \ m P a \ s }$ for the commercial electrolyte of $1 . 0 \mathrm { ~ M ~ } \mathrm { L i P F } _ { 6 }$ in ethylene carbonate (EC): DMC: ethyl methyl carbonate (EMC) (1: 1: 1 by vol). Meanwhile, its ionic conductivity $( 3 . 2 \mathrm { m S } \mathrm { c m } ^ { - 1 } )$ is almost three times that of the ILE $( 1 . 1 \mathrm { m S ~ c m ^ { - 1 } }$ ). The electrochemical stability of different electrolytes was measured by linear sweep voltammetry (LSV). The results (shown in Figure S2, Supporting Information) indicate that the electrolytes are oxidation-resistant over $5 . 4 \mathrm { ~ V ~ }$ versus $\mathrm { L i } / \mathrm { L i ^ { + } }$ , meaning that they are suitable for most lithium battery systems. Based on the above experimental results, the electrolyte with an IL/HFE molar ratio of 1:2 was selected as the representative LHCE, and the ILE and commercial electrolyte were also investigated for comparison.  The electrolyte viscosity also influences its wettability on the separator. As shown in Figure S3 (Supporting Information), because of the low viscosity of the HFE diluent, the LHCE exhibits superior wettability on the separator than the ILE and even the commercial electrolyte, which is more beneficial for cell performance. Besides, combustion tests of the LHCE and the commercial electrolyte (Figure 1b; and Video S1, Supporting Information) reveal that the latter is highly flammable, while the former cannot be ignited (show in Video S2, Supporting Information) due to the intrinsic nonflammability of the IL and HFE solvents. Thus, the LHCE is expected to display enhanced safety in LMBs.  Raman spectroscopy and MD simulation were used to understand $\mathrm { L i ^ { + } }$ solvation structure in the novel LHCE. In the Raman spectra, the ${ \sf S } { = } { \sf O }$ stretching vibration peak of $\mathrm { F S I ^ { - } }$ is shifted from $1 2 1 6 ~ \mathrm { c m } ^ { - 1 }$ in pure $[ \mathrm { P P } _ { 1 3 } ] [ \mathrm { F S I } ]$ to $1 2 2 3 ~ \mathrm { c m } ^ { - 1 }$ in the ILE (Figure 1c) due to the coordination of $\mathrm { F S I ^ { - } }$ with $\mathrm { L i ^ { + } }$ . [11c,13a] Adding the HFE diluent to ILE caused the peak of $\mathrm { L i ^ { + } } .$ -coordinated $\mathrm { F S I ^ { - } }$ to shift from near $1 2 2 3 { \mathrm { - } } 1 2 2 7 \ { \mathrm { c m } } ^ { - 1 }$ in LHCE, indicating even stronger coordination between $\mathrm { L i ^ { + } }$ and $\mathrm { F S I ^ { - } }$ in LHCE.[11a,c] Meanwhile, MD simulations reveal that the peak of the radial distribution function (RDF) at $1 . 9 5 \mathrm { ~ \AA ~ }$ , which is assigned to the $\mathrm { L i - O _ { F S I } }$ coordination structure, significantly increases in LHCE compared to ILE (Figure 1d), also indicating enhanced $\mathrm { L i ^ { + } { - } F S I ^ { - } }$ coordination. Furthermore, the Raman vibration band of HFE at $8 4 0 { - } 8 6 0 ~ \mathrm { c m } ^ { - 1 }$ does not change (Figure 1c) for LHCE and no distinct peaks of the $_ { \mathrm { L i - O _ { H F E } } }$ pair or $\mathrm { L i - N _ { P P 1 3 } }$ pair is found in the RDF for LHCE (Figure 1d), suggesting that the interaction between $\mathrm { L i ^ { + } }$ and $\mathrm { H F E } / \mathrm { P P _ { 1 3 } } ^ { + }$ is very weak.[11a,b] Fourier transform infrared spectroscopy (FTIR) was also used to characterize the HFE solvent, ILE, and LHCE. The results (Figure S4, Supporting Information) also reveal characteristic vibrations of HFE at 1280 and $6 7 0 \mathrm { c m } ^ { - 1 }$ that do not shift distinctly in the case of LHCE. The intensity of the two $- \mathrm { S O } _ { 2 }$ stretching vibration peaks from $\mathrm { F S I ^ { - } }$ (at ${ \approx } 1 3 6 0$ and $1 3 8 0 ~ \mathrm { c m ^ { - 1 } }$ ) is obviously different in ILE and LHCE.[13b] Another peak of $\mathrm { F S I ^ { - } }$ at $\approx 1 1 7 0 \ c m ^ { - 1 }$ in ILE is also shifted to higher wavenumber of 1177 $\mathrm { c m } ^ { - 1 }$ in LHCE. These FTIR results are consistent with the Raman results, also demonstrating the strengthened coordination of $\mathrm { F S I ^ { - } }$ with $\mathrm { L i ^ { + } }$ and weak $\mathrm { L i ^ { + } { - } H F E }$ interaction. MD simulation also reveals that contact ion pairs (CIPs, $\mathrm { F S I ^ { - } }$ coordinated one $\mathrm { L i ^ { + } }$ ) and aggregates (AGGs, $\mathrm { F S I ^ { - } }$ coordinated two $\mathrm { L i ^ { + } } )$ ) [4] are dominant in both ILE and LHCE, and the proportion of AGG is relatively higher in LHCE (Figure  1e; and Figure S5, Supporting Information). The major $\mathrm { L i ^ { + } }$ coordination structures in ILE and LHCE are shown in Figure 1f, which are mutually validated by the Raman and FTIR characterizations. The above results indicate that the HFE diluent and $\mathrm { P P _ { 1 3 } } ^ { + }$ cations do not participate in the solvation sheath of $\mathrm { L i ^ { + } }$ cations, and a localized highly concentrated $\mathrm { L i ^ { + } { - } F S I ^ { - } }$ coordination structure exists in the ionic liquid-based LHCE.[11d]

- Linked text (the paper's own sentences, as linked by the PDF parser): The ability of an electrolyte to inhibit Li dendrite growth is necessary for its application in LMBs. To evaluate this ability, $\mathrm { L i } / \mathrm { C u }$ cells with the three different electrolytes mentioned above were assembled, and their Li plating/stripping performances were compared at $0 . 5 \mathrm { \ m A \ c m ^ { - 2 } }$ and an areal capacity of $0 . 5 \mathrm { m A }$ h $\mathrm { c m } ^ { - 2 }$ . From Figure 2a; and Figure S6a (Supporting Information), the commercial electrolyte exhibits a low average CE of ${ \approx } 8 3 \%$ in the first 30 cycles, and then the capacity and reversibility significantly decrease due to irreversible reactions between the deposited Li metal and carbonate electrolyte.[10,14] The ILE demonstrates a higher average CE of ${ \approx } 9 8 . 8 \%$ until 250 cycles, followed by increased voltage polarizations and random voltage oscillations in Figure S6b (Supporting Information), which may be owing to a sudden short circuit caused by dendrite growth.[2b] From Figure 2a; and Figure S6c (Supporting Information), the LHCE displays a lower overpotential, smaller polarization, and longer cycling lifespan than both the commercial electrolyte and the ILE, accompanied by an ultrahigh average CE of ${ \approx } 9 9 . 4 \%$ over 800 cycles.  To our best knowledge, a high current density will aggravate the evolution of Li dendrites and quickly generate a fairly resistive SEI on the Li metal surface because the fresh Li will be continuously attacked by the electrolyte, leading to a large polarization and short lifespan of LMBs.[10] Here, the rate capability of the $\mathrm { L i } / \mathrm { C u }$ cell with LHCE was evaluated at different current densities. As shown in Figure  2b, despite increasing voltage polarization at higher current density, the cell could still work at a very high current density of $1 0 \mathrm { \ m A \ c m ^ { - 2 } }$ . Furthermore, the rate capabilities and long-term cycling performances of Li/Li symmetric cells with different electrolytes are shown in Figure S7 (Supporting Information) and Figure 2c. Apparently, the cell with LHCE exhibits more stable voltage profiles than that with the commercial electrolyte when cycled at different current densities. Unlike the dramatic increase of voltage polarization and short cycle lifespan for the Li/Li cell with commercial electrolyte, the Li/Li cell with LHCE shows excellent cycling stability over $1 0 0 0 \ \mathrm { h }$ at the exceptionally high current density of $1 0 \mathrm { \ m A \ c m ^ { - 2 } }$ and an areal capacity of $1 \textrm { m A }$ h $\mathrm { c m } ^ { - 2 }$ , which corresponds to 5000 plating/stripping cycles. Meanwhile, the LHCE displays much lower voltage polarization than the ILE, indicating a reduced cell impedance that is beneficial for the cell performance. The outstanding cycling and rate performances of the LHCE are ascribed to its good ability to prevent Li dendrite growth and homogenize Li deposition behavior. A survey of LHCEs in LMBs from the recent literatures is given in Table S1 (Supporting Information). Note that these reported LHCEs are based on organic solvents instead of IL solvents. Compare with organic solvents, such as DMC, the ILs show higher safety because of their low volatility and nonflammability. However, the large-scale application of ILEs is restricted by their high costs, high viscosity, low ambient-temperature ionic conductivity, and poor wettability on the separators. Adding HFE diluent into ILEs can exploit the advantages of ILEs while avoiding their shortcomings, and so this strategy may have great commercial potential. Moreover, it is noteworthy that compared to previous studies, this work presents higher ionic conductivity and better cycling performance with long cycling life and high CE in the $\mathrm { L i } / \mathrm { C u }$ cell.

- Linked text (the paper's own sentences, as linked by the PDF parser): To further investigate Li deposition behavior and Li dendrite growth in different electrolytes, the cycled $\mathrm { L i } / \mathrm { C u }$ cells were disassembled, and morphologies of the Li-plated Cu foils were characterized by SEM. Figure 3a,b is cross-sectional and top-view SEM images of the Li metal deposited on Cu foils in the commercial carbonate electrolyte. Consistent with a previous report,[2] loose dendritic Li is deposited in this case, and the many protruding needle-like dendrites can easily penetrate the separator and cause short circuit of LMBs. According to Figure  3c,d, the Li metal deposited in ILE exhibits a loose nodule-like structure with rounded edges, making them less prone to penetrate the separator. In contrast to these two cases, a flatter, smoother, and denser morphology of Li deposition is obtained in the LHCE (Figure  3e,f), indicating more homogenous Li deposition behavior and an outstanding ability to suppress Li dendrite growth in LHCE than the commercial electrolyte and ILE. The same results are also visible from the photographs shown as insets in Figure  3: Li deposition in the commercial electrolyte and ILE is uneven with some exposed Cu foil, while the Li deposited in LHCE has very bright metallic luster and completely covers the Cu foil. The process of Li deposition in LHCE and commercial electrolyte was also monitored by in situ optical microscopy, shown in Figure S8 (Supporting Information). Obviously, in LHCE the surface of deposited Li remains smooth and dense after $1 0 \ \mathrm { m i n }$ at $3 \mathrm { \ m A \ c m ^ { - 2 } }$ current density, whereas a mossy and dendritic Li deposition morphology is obtained in the commercial electrolyte. Furthermore, even when the deposition current density is increased to  $5 \mathrm { \ m A \ c m ^ { - 2 } }$ , homogenous and dense Li deposition persists in the LHCE (Figure S9, Supporting Information). Such dense and homogenous Li deposition will effectively minimize the surface area of deposited Li film and help reduce its side reactions with the electrolyte. As a result, the LHCE exhibits excellent stripping/plating cycling performance and high CE in the $\mathrm { L i } / \mathrm { C u }$ and Li/Li cells.

- Linked text (the paper's own sentences, as linked by the PDF parser): XPS analysis was used to explore components of the SEI layer generated on the Li metal surface. As shown in Figure 4a,b; and Figure S10 (Supporting Information), in the commercial electrolyte, the SEI layer on Li metal surface contains a large amount of decomposition products generated by carbonate solvents and $\mathrm { P F } _ { 6 } { } ^ { - }$ anions (e.g., $\mathrm { R O C O } _ { 2 } \mathrm { L i }$ , $\mathrm { L i } _ { 2 } \mathrm { C O } _ { 3 }$ , LiF, POF, and $\mathrm { C - O / C - C / C - H / C - L i ) }$ .[15] For ILE and LHCE, the F 1s and O 1s XPS spectra indicate that the SEI layer contains more inorganic substances, such as LiF $( 6 8 5 . 0 ~ \mathrm { e V } )$ , $\mathrm { L i } _ { 2 } \mathrm { O }$ ( $5 2 8 . 6 \ \mathrm { e V } )$ ), and compounds with ${ \sf S } { = } { \sf O }$ bond $( 5 3 2 . 3 ~ \mathrm { e V } )$ , which might enhance the mechanical strength to prevent Li dendrite growth and SEI breakdown.[5c,15] To understand the mechanism of SEI layer formation, the projected density of states (PDOS) of different ions and solvents in the ILE and LHCE was obtained by density functional theory (DFT) calculations. The PDOS results in Figure $_ { 4 \mathrm { c } }$ also demonstrate that the lowest unoccupied molecular orbital (LUMO, the orbital primarily attacked by electrons following reduction)[4,5c] is located at the $\mathrm { F S I ^ { - } }$ anions, indicating that these anions are preferentially decomposed over $\mathrm { P P _ { 1 3 } } ^ { + }$ cations and HFE solvent in the ILE and LHCE. Based on the XPS results and previous reports,[16a,b] we propose the reactions of $\mathrm { F S I ^ { - } }$ anion decomposition as shown in Figure S11 (Supporting Information). Consequently, the SEI layer on the Li metal anode formed in the ILE and LHCE contains more inorganic substances, such as LiF, $\mathrm { L i } _ { 2 } \mathrm { O }$ , and compounds with ${ \sf S } { = } { \sf O }$ bond from LiFSI decomposition.  Based on the above SEM, XPS, and theoretical simulation results, the proposed $\mathrm { L i ^ { + } }$ solvation structure and mechanisms for SEI formation in different electrolytes are illustrated in Figure  4d–f. In the commercial electrolyte, $\mathrm { L i ^ { + } }$ cations are solvated by a large amount of carbonate solvent molecules and a few $\mathrm { P F } _ { 6 } { } ^ { - }$ anions. The solvated $\mathrm { L i ^ { + } }$ cations first migrate to the Li anode and enter the inner Helmholtz layer, and then they are reduced to form an SEI layer on the Li anode surface.[11a,16] Hence, the formed SEI layer contains abundant organic components derived from the decomposition of carbonate solvents.[16d] In the ILE and LHCE, the solvated $\mathrm { L i ^ { + } }$ cations are mainly coordinated with $\mathrm { F S I ^ { - } }$ anions, and the added HFE in LHCE will let more $\mathrm { F S I ^ { - } }$ anions participate in the $\mathrm { L i ^ { + } }$ solvation sheath. Consequently, the SEI layer contains more inorganic components like LiF, $\mathrm { L i } _ { 2 } \mathrm { O }$ , and compounds with ${ \sf S } { } = { } \mathrm { O }$ bond arising from the decomposition of $\mathrm { F S I ^ { - } }$ anions, which help suppress Li dendrite growth and homogenize Li deposition.  Besides the benefits from a robust SEI layer with high mechanical strength, diffusion kinetics of $\mathrm { L i ^ { + } }$ cations is another key factor determining the Li deposition behavior.[16c,17] In commercial electrolyte, because of the uneven distribution of relatively sparse $\mathrm { L i ^ { + } }$ cations and random natural convection in the electrolyte, some $\mathrm { L i ^ { + } }$ cations will move faster or slower than others, and the resultant strong concentration gradient creates fluctuating $\mathrm { L i ^ { + } }$ flux near the electrode and induces heterogeneous Li deposition,[17] as shown in Figure 4d. In contrast, in the ILE and LHCE, the highly concentrated or locally highly concentrated $\mathrm { L i ^ { + } }$ cations attenuate the concentration gradient and produce uniform $\mathrm { L i ^ { + } }$ fluxes, as shown in Figure 4e,f. Thus, lithium deposition in these cases is more homogeneous than that in commercial electrolyte. Furthermore, due to the reduced electrolyte viscosity and faster $\mathrm { L i ^ { + } }$ transport after adding HFE, the $\mathrm { L i ^ { + } }$ consumed in electroplating will be quickly replenished, eventually generating a much denser lithium deposition morphology in the LHCE than that in the ILE. This point is demonstrated by the measured $\mathrm { L i ^ { + } }$ transference number $( t _ { \mathrm { L i ^ { + } } } )$ in Figure S12 (Supporting Information), with LHCE showing a higher $t _ { \mathrm { L i ^ { + } } }$ compared to ILE (0.313 vs 0.165). The MD simulation results (Figure S13a, Supporting Information) also display distinct RDF peaks at $2 . 5 \mathrm { ~ \AA ~ }$ for the $\mathrm { H } _ { \mathrm { H F E } } { - } \mathrm { O } _ { \mathrm { F S I } }$ , $\mathrm { H } _ { \mathrm { H F E } } { - } \mathrm { F } _ { \mathrm { F S I } }$ and $\mathrm { H } _ { \mathrm { P P 1 3 } } \mathrm { - F } _ { \mathrm { H F E } }$ pairs, which are typical structures of hydrogen-bond interactions in LHCE as shown in Figure S13b (Supporting Information). Therefore, the HFE diluent can form hydrogenbond interaction with the $\mathrm { P P _ { 1 3 } } ^ { + }$ cations and/or $\mathrm { F S I ^ { - } }$ anions and inhibit their transport.[18]

To investigate its prospect as a safe electrolyte for LMBs, ${ \mathrm { L i F e P O } } _ { 4 }$ (LFP)/ Li cells with LHCE were assembled, and the rate performance and long-term cycling performance were measured. LFP/Li cells with ILE and commercial electrolyte were also assembled for comparison. All the above results demonstrate that the addition of HFE diluent is beneficial, and the resultant IL-based LHCE is very promising for high-performance LMB applications.
