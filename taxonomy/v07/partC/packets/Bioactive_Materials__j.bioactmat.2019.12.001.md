- path: /home/aid1/Documents/causalmat/matmech/Bioactive_Materials/j.bioactmat.2019.12.001/images/a779cd88fb681aef9303cc4cb013e9b526856afc20f9c6df45bf593492977068.jpg
- caption: Fig. 11. Schematic illustration of $\mathbf { M A O } / \mathrm { T a } _ { 2 } \mathrm { O } _ { 5 }$ coating through ALD for (a) 1 and (b) 500 cycles and (c) the reaction equation of $\mathrm { T a } _ { 2 } \mathrm { O } _ { 5 }$
- Linked text (the paper's own sentences, as linked by the PDF parser): ALD technology is a self-limiting and self-saturating method to form a thin film through alternately introducing a gas precursor pulse into the reaction chamber and occurring a surface chemical reaction on the substrate surface. Obviously, the deposition of ${ \mathrm { T a } } _ { 2 } { \mathrm { O } } _ { 5 }$ using ALD is a discontinuous process consisting of several semi-reactive sequences. Taking $\mathrm { T a [ N ( C H C H _ { 3 } ) _ { 2 } ] _ { 3 } [ N H C ( C H _ { 3 } ) _ { 3 } ] }$ as Ta source and water vapor as O source, the whole reaction could be divided into two steps in Fig. 11a. The first step (Reaction 1), $\mathrm { T a [ N ( C H C H _ { 3 } ) _ { 2 } ] _ { 3 } [ N H C ( C H _ { 3 } ) _ { 3 } ] }$ was introduced into the reaction chamber in the form of a gas. Then, a reaction occurred on MAO coating surface (a large number of –OH active sites on MAO coating surface) to rob the H of MAO- $\mathrm { O H ^ { * } }$ $^ { \ast }$ representing a functional group adsorbed on the deposition surface) and form the intermediate layer $\mathrm { T a { - } O { - } T a [ N ( C H C H _ { 3 } ) _ { 2 } ] _ { 3 } } ^ { * }$ . And a by-product ${ \mathrm { N H } } _ { 2 } { \mathrm { C } } ( { \mathrm { C H } } _ { 3 } ) _ { 3 }$ was formed in this process. After the reaction was completed, the remaining Ta source and reaction by-products were purged bypassing high-purity nitrogen [45,46]. The second step (Reaction 2), an excess of O source (i.e. water vapor) was introduced to react with the reactive site $\mathbf { - N } ( \mathrm { C H C H } _ { 3 } ) _ { 2 }$ of the intermediate layer to obtain a layer of ${ \mathrm { T a } } _ { 2 } { \mathrm { O } } _ { 5 }$ and reaction by-products [47]. Due to the steric hindrance effect, the O source would first react with $\mathrm { - N H C ( C H _ { 3 } ) _ { 3 } }$ and then replaced the $\mathbf { - N } ( \mathrm { C H C H } _ { 3 } ) _ { 2 }$ groups. After the residual gas was purged with high purity nitrogen, one cycle ended. A $\mathrm { T a } _ { 2 } \mathrm { O } _ { 5 }$ film was obtained in each cycle, and each of the half-reacted precursors could be adsorbed inside the micropores and microcracks of MAO coating. Finally, a dense $\mathrm { T a } _ { 2 } \mathrm { O } _ { 5 }$ coating was obtained after a plurality of cycles of deposition (Fig. 11b).
