The experimental process is illustrated in Fig. 1a, and described as follows. Firstly, to obtain uniformed precipitates, the as-received sheet was solution treated at $4 1 0 ^ { \circ } \mathrm { C }$ for $^ { 8 \mathrm { h } }$ , which still possessed a typical strong basal texture with a slightly decreased texture intensity, as shown in Fig. 1c. Cubic block samples with $1 0 \mathrm { m m } \times 1 0 \mathrm { m m } \times 1 5 \mathrm { m m }$ along ND, TD and RD were machined from the aged sheet (hereafter named sample A). Secondly, to transform the precipitate orientation, sample  A was compressed along TD at a constant strain rate of $1 0 ^ { - 3 } \mathrm { { s } ^ { - 1 } }$ (hereafter named sample AC). Two strain values (8 and $13 \%$ ) were carried out to obtain the maximum twinning proportion, which expected most grains were completely twinned. Thus, the grain orientation will change from $c$ -axis // ND to $c$ -axis $/ /$ TD. Finally, the compressed samples were annealed at $2 5 0 ^ { \circ } \mathrm { C }$ for $3 0 \mathrm { { m i n } }$ (hereafter named sample ACA). This treatment could have a slight influence on the texture, but the main grain orientation remains $c$ -axis $/ /$ TD.  To avoid the influence of texture on mechanical properties, all the compression test samples with a dimension of $4 . 5 \times 4 . 5 \times 7 . 5 \mathrm { m m }$ $( \mathrm { l e n g t h } \times \mathrm { w i d t h } \times \mathrm { h e i g h t } )$ were machined along $4 5 ^ { \circ }$ to ND (in the ND-TD plane). Mechanical properties were evaluated by compression test with a strain rate of $1 \times 1 0 ^ { - 3 } \ \mathrm { s ^ { - 1 } }$ at RT using a MTS-CMT5105. Note that the compressive axis is along the height direction, as demonstrated in Fig. 1d. All compression tests were repeated 3 times for each type of samples to get the representative results.

It could account for the phenomenon that the ductility and strength of sample $\mathrm { A C } { - } 4 5 ^ { \circ }$ improved simultaneously, and the strength of sample ACA- $4 5 ^ { \circ }$ enhanced but the ductility not decreased.
