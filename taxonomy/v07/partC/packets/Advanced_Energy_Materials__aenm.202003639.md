- Linked text (the paper's own sentences, as linked by the PDF parser): The calculated density of states (DOS) explained why the insertion of ${ \mathrm { Z n } } ^ { 2 + }$ would induce an intense Jahn-Teller effect. From a physical perspective, the Jahn-Teller effect is the name applied to some phenomena in systems with degenerate electronic states since the degeneracy will make the configuration of atoms unstable.[39] Therefore, structural distortion occurs as an external consequence of relieving the degenerate states and lowering the total energy. The sharp peaks near the Fermi level in Figure $_ { 7 \mathrm { a - c } }$ demonstrated that the systems without ${ \mathrm { Z n } } ^ { 2 + }$ possessed degenerate states while Figure 7d–f manifested that the peaks attenuated and broadened, indicating the relief of the degeneracy with the intercalation of ${ \mathrm { Z n } } ^ { 2 + }$ . Thus, the insertion of ${ \mathrm { Z n } } ^ { 2 + }$ is critical to relieve degeneracy and induce an intense Jahn-Teller effect, resulting in a more stable atomic configuration.

- Linked text (the paper's own sentences, as linked by the PDF parser): Furthermore, the phase transition mechanism was also explained from a physicochemical perspective. According to the theory by Henkelman et  al.,[40] the phase transition is the result of three competing interactions inside PBAs: Coulomb attraction, ${ \mathrm { d } } \mathrm { - } \pi$ covalent interaction, and Pauli repulsion (see details in the Experimental Section). Here we only consider that Coulomb attraction and ${ \mathrm { d } } \mathrm { - } \pi$ covalent interaction are the major competing factors based on our results. The Coulomb attraction favors the rhombohedral phase, while the ${ \mathrm { d } } \mathrm { - } \pi$ covalent interaction favors the monoclinic phase. On the one hand, the Coulomb attraction between ${ \mathrm { Z n } } ^ { 2 + }$ and $\mathrm { N } ^ { - }$ is obviously stronger than the one between $\mathrm { K } ^ { + }$ and $\mathrm { N ^ { - } }$ since ${ \mathrm { Z n } } ^ { 2 + }$ has more net charges. Thus, the insertion of $Z \mathrm { n } ^ { 2 + }$ enhances the Coulomb attraction in the system. On the other hand, the calculated charge density difference (Figure 8a–c) clearly manifests the presence of significant ${ \mathrm { d } } \mathrm { - } \pi$ interaction during the process of the deintercalation of $\mathrm { K } ^ { + }$ .[41] However, with the intercalation of $Z \mathrm { n } ^ { 2 + }$ (Figure 8d–f), the ${ \mathrm { d } } \mathrm { - } \pi$ interaction was suppressed by the induced Jahn-Teller distortion. In general, due to the insertion of ${ \mathrm { Z n } } ^ { 2 + }$ and the consequent Jahn-Teller effect, the Coulomb attraction intensified while the ${ \mathrm { d } } \mathrm { - } \pi$ interaction attenuated. Therefore, the balance of phases tipped to the rhombohedral side and the phase transition would happen, which could be schematically depicted in Figure 9.

- Linked text (the paper's own sentences, as linked by the PDF parser): Furthermore, the phase transition mechanism was also explained from a physicochemical perspective. According to the theory by Henkelman et  al.,[40] the phase transition is the result of three competing interactions inside PBAs: Coulomb attraction, ${ \mathrm { d } } \mathrm { - } \pi$ covalent interaction, and Pauli repulsion (see details in the Experimental Section). Here we only consider that Coulomb attraction and ${ \mathrm { d } } \mathrm { - } \pi$ covalent interaction are the major competing factors based on our results. The Coulomb attraction favors the rhombohedral phase, while the ${ \mathrm { d } } \mathrm { - } \pi$ covalent interaction favors the monoclinic phase. On the one hand, the Coulomb attraction between ${ \mathrm { Z n } } ^ { 2 + }$ and $\mathrm { N } ^ { - }$ is obviously stronger than the one between $\mathrm { K } ^ { + }$ and $\mathrm { N ^ { - } }$ since ${ \mathrm { Z n } } ^ { 2 + }$ has more net charges. Thus, the insertion of $Z \mathrm { n } ^ { 2 + }$ enhances the Coulomb attraction in the system. On the other hand, the calculated charge density difference (Figure 8a–c) clearly manifests the presence of significant ${ \mathrm { d } } \mathrm { - } \pi$ interaction during the process of the deintercalation of $\mathrm { K } ^ { + }$ .[41] However, with the intercalation of $Z \mathrm { n } ^ { 2 + }$ (Figure 8d–f), the ${ \mathrm { d } } \mathrm { - } \pi$ interaction was suppressed by the induced Jahn-Teller distortion. In general, due to the insertion of ${ \mathrm { Z n } } ^ { 2 + }$ and the consequent Jahn-Teller effect, the Coulomb attraction intensified while the ${ \mathrm { d } } \mathrm { - } \pi$ interaction attenuated. Therefore, the balance of phases tipped to the rhombohedral side and the phase transition would happen, which could be schematically depicted in Figure 9.
