- Linked text (the paper's own sentences, as linked by the PDF parser): Fig. 1 depicts the optical micrographs of AZ91 base alloy and $\mathrm { { A Z 9 1 - S i C _ { p } } }$ composites with 5, 10, 15, 20 and $2 5 \ \mathrm { w t } \%$ $\mathrm { S i C _ { p } }$ content. A typical two phase microstructure of AZ91 alloy with $\mathsf { \Omega } \mathsf { \Omega } \mathsf { q } \mathrm { - } \mathsf { M } \mathsf { g }$ phase and $\mathrm { \beta - M g } _ { 1 7 } \mathrm { A l } _ { 1 2 }$ phase along and adjacent to the grain boundaries is shown in Fig. 1(a). Nearuniform distribution of $\mathrm { S i C _ { p } }$ can be noted in microstructure of the composites depicted in Fig. 1 (bef). Moreover, the reinforcements are found to be dispersed in the matrix with very few agglomerations. Generally, the increase in particle reinforcement content tends to increase the agglomeration in composites. This is attributed to the finer size of the reinforcements and variations in parameters like stirring time, stirring speed, stirring temperature, etc [11]. Moreover, noticeable presence of $\mathbf { M g O }$ in the form of white patches or that of $\mathrm { M g } _ { 2 } \mathrm { S i }$ in needle like or dots cannot be evidenced in the microstructure as of XRD results. This nullifies the effect of such phases on formation of microstructure.  Moreover, the grain size is reduced from 65 microns for the base alloy to 34 microns for $5 \ \mathrm { w t } \%$ $\mathrm { S i C _ { p } }$ containing composites and then to 22 microns for composite containing 10 wt $\%$ $\mathrm { S i C _ { p } }$ . However, the grain size reduction is comparitively negligible for higher reinforcement containing composites i.e. 21 microns for $2 5 ~ \mathrm { w t \% ~ S i C _ { p } }$ .  The possible refinement mechanism behind reduction in grain size of the matrix due to the presence of $\mathrm { S i C _ { p } }$ is heterogeneous nucleation. The reinforcing $\mathrm { S i C _ { p } }$ which can act as the heterogeneous nucleation site may get captured by growing $\mathbf { M g }$ crystals and finally stay within the $\mathbf { M g }$ grains in the composites. Hence, the presence of $\mathrm { S i C _ { p } }$ within the grain boundaries of the composite is justified. Moreover, certain crystallographic orientation relationships between the particle and matrix and the restricted growth of $\mathbf { M g }$ grains by $\mathrm { S i C _ { p } }$ during solidification can further contribute to the reduction in grain size [11,12] which is evidenced by the presence of the reinforcements around the grains as clusters.

- Linked text (the paper's own sentences, as linked by the PDF parser): Interfacial reactions are of extreme importance while considering the mechanical and creep properties of the composite as the load transfer between the reinforcements and the matrix is governed by the interface between them. The SEM microstructure of $\mathrm { A Z ^ { 9 1 - 2 0 S i C _ { p } } }$ composite shown in Fig. 2a reveals good distribution of the particles. The high magnification SEM micrograph in Fig. 2b shows the intimate bonding of $\mathrm { S i C _ { p } }$ with $\mathbf { M g }$ matrix which nullifies the occurance of any significant chemical reaction at the $\mathrm { M g - S i C _ { p } }$ interfaces.  Moreover, the sharp and clean (precipitate and reaction free) interface also depicts good interfacial integrity of $\mathrm { S i C _ { p } }$ with the matrix. Studies conducted on the feasibility of compo-cast AZ91/SiC composites had similar conclusion stating that SiC wetted well with $\mathbf { M g }$ and $\mathbf { M g }$ is a better host for $\mathrm { S i C _ { p } }$ embedment than Al. Moreover, the presence of Al in the AZ91 alloy has tremendous influence in improving the wettability of $\mathrm { S i C _ { p } }$ reinforcements [13].

- Linked text (the paper's own sentences, as linked by the PDF parser): The variation in yield strength (YS) and ultimate tensile strength (UTS) of AZ91 alloy with respect to the various $\mathrm { S i C _ { p } }$ content is depicted as histogram in Fig. 3. The YS of the composites during tension shows a gradual increase with respect to the increment in amount of reinforcements. Studies pertaining to the tensile strength of $\mathbf { M g }$ matrix composites have revealed that within a certain range, both yield strength and elastic modulus of the composites increase linearly with increase in amount of reinforcement. The key strengthening mechanisms in $\mathbf { M g }$ matrix composites are particle strengthening, work hardening, load transfer and grain refinement of the matrix alloy by the reinforcement [2]. The finely dispersed $\mathrm { S i C _ { p } }$ strengthen the $\mathbf { M g }$ matrix by blocking the dislocation motion within the composites. Also, the smaller sized grains have improved strength within the elastic region and facilitate enhanced tensile properties for the composites at room temperature [14]. In the present composite system, the grain size reduction for $\mathrm { A Z 9 1 - 5 S i C _ { p } }$ and $\mathrm { A Z 9 1 - 1 0 S i C _ { p } }$ is more predominant compared with AZ91 alloy with 15, 20 and $2 5 \ \mathrm { w t } \%$ $\mathrm { S i C _ { p } }$ . The variation in YS also depicts similar characteristics, with increment being high for 5 and $1 0 \mathrm { \ S i C _ { p } }$ containing composites as of composites with higher amount of reinforcing phase.

These ridges are indicative of ductile failure and so are the pockets of dimples of varying size and shape in the fracture surface. Moreover, the development of a resultant triaxial stress state in the matrix aids in limiting the flow stress of the composite [16]. Also, brittle fracture region increases with increase in $\mathrm { S i C _ { p } }$ when compared to the ductile region.

- Linked text (the paper's own sentences, as linked by the PDF parser): Fig. 6 shows exemplarily creep curves of tests performed with $\mathrm { A Z 9 1 - 2 5 S i C _ { p } }$ composite at a temperature of $1 7 5 ~ ^ { \circ } \mathrm { C }$ with stress levels of 80, 100 and $1 2 0 \ \mathrm { M P a }$ . The variation in creep deformation of the composite as a function of time for different applied loads depicted in Fig. 6a symbolizes a typical creep curve. The creep deformation increases with increase in  stress and associated time decreases as the load elevates.   
Hence, increase in applied stress reduces the test duration.  The creep rate of the composite is plotted against time for varying stress levels in Fig. 6b. The curves have similar characteristics with those from Fig. 6a in terms of variation of creep rate and time with respect to applied load. Moreover, reduction in minimum creep rate can also be evidenced with decreasing the applied load. The creep curves in Fig. 6c are the diagrammatical representation of the creep rate of the composite against its creep deformation under different loading conditions. It is clearly visible that minimum creep rate is reached in the first $10 \%$ of deformation and with increase in applied load, the deformation at which the minimum creep rate occurs, increases.  Creep deformation is the representation of the time dependant plastic flow occurring in crystalline and noncrystalline materials under an applied load which need not to be above the elastic limit of the material. Moreover, it is well documented that the classical creep curve of materials consists of three distinct stages namely primary stage in which strain rate decreases with increase in time, a secondary stage where stain rate is reasonably constant and ternary stage where strain rate increases with time [18]. However, in the case of discontinuously reinforced composites, duration of secondary stage is relatively shorter. In such cases, the deformation mechanisms are best described using minimum creep rate which can be observed most readily in plots of creep rate against time [19].  The stress exponent n gives information about ratecontrolling deformation mechanisms during creep $( \mathtt { n } = 3$ represents creep controlled by viscous glide [20], ${ \mathfrak { n } } = 5$ is for creep controlled by high temperature climb of dislocation due to diffusion of the lattice [21], $\mathrm { n } = 7$ symbolizes creep by low temperature climb of dislocation due to diffusion of the core [22], ${ \mathfrak { n } } = 8$ is for lattice diffusion controlled creep deformation [23]).  The n values are determined by plotting the minimum creep rates in a double logarithmic plot versus stress field as shown in Fig. 7a. The filled squares in the graph represent AZ91 and the empty ones are those of the composites reinforced with different amounts of $\mathrm { S i C _ { p } }$ . The base alloy and the composites with lower reinforcement content (5 and 10 wt $\%$ ) evince less significant difference in minimum creep rates. However, the composites containing 15, 20 and $2 5 \ \mathrm { \ w t \% \ S i C _ { p } }$ have an improved creep resistance. The calculated stress exponents n for the base alloy and composites are given in Table 1.  The high stress dependence of creep rate is due to the presence of threshold stress $( \sigma _ { \mathrm { t h r } } )$ , the stress below which no creep deformation occurs, and is attributed to the interactions of the dislocation with the reinforcement. There are several explanations for threshold stress. It is often referred as the Orowan stress, which is the additional stress needed for bowing the dislocations between the reinforcements [26]. The $\sigma _ { \mathrm { t h r } }$ is also referred as the additional back stress which is required for climbing over an obstacle or as the stress needed for detaching dislocations from obstacles [27,28]. Hence, the stress term $( \sigma )$ in eq (1) is to be replaced with the term of effective stress $( \sigma _ { \mathrm { e f f } } )$ to avoid the anomalous nature of the stress exponents. The true stress exponent values of the composites lie in the range of 5.4 and 5.8. As per literature, this can be attributed to the dislocation climbing at higher temperature [21,30].
