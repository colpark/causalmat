These results elucidate that electron orbitals of ${ \mathrm { C O } } _ { 2 }$ partially participated in the dispersion for interaction with orbitals of $\mathtt { C u }$ atoms [64,65]. Fig. $6 ( \mathsf { b } )$ shows the projected density of states (PDOS) of $\mathrm { ~ C u ~ } 3 d -$ orbitals for $\mathsf { C u C R  S C C }$ and $2 p$ -orbitals of free ${ \mathsf { C O } } _ { 2 }$ . Fig. 6(c) shows the DOS of CuCR SCC and CR with a comparison for the spin polarization. Before ${ \mathrm { C O } } _ { 2 }$ adsorption (left plots), pure CdS (CR) exists a semiconducting character with S atoms domination for both valence and conduction band [66]. However, since the induced Cu clusters conjunction with neighboring Cd vacancies, the density of states for S atoms over CuCR SCC leans towards the valence band far from the Fermi level (the dotted line in Fig. 6(c)), leading to the shifted band states [54,67]. After ${ \mathsf { C O } } _ { 2 }$ adsorption, Cu atoms are significantly contributed to the total density of states of CuCR SCC as comparison with CR (right plots in Fig. 6(c)), illustrating the vital effect of Cu clusters on enhancement in the ${ \mathrm { C O } } _ { 2 }$ adsorption properties [68,69]. In addition, we demonstrate that there is a coupling configuration association between Cu and S, since Cu $d$ -orbitals hybridized with $p \cdot$ -orbitals of S atoms (Figs. S24 and S25) [62]. These theoretical results prove the rationality of the proposed coordination mechanism in this studied CuCR SCC system, of which the well-defined Cu clusters are directly immobilized on Cd-defective CdS nanorods Fig. $6 ( \mathrm { d } )$ unveils that the charge carriers are rich accumulation surrounding the interfacial atomic conjunction between Cu and S atoms. The presence of Cd vacancies provide the centers for charge transfer from CdS to Cu clusters, which promotes charge enrichment in the local coordination environment.
