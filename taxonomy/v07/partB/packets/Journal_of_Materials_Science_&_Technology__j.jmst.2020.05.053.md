- Linked text (the paper's own sentences, as linked by the PDF parser): Engineering tensile stress-strain curves of the $\mathsf { A l } _ { 0 . 9 } \mathsf { C o F e N i } _ { 2 }$ EHEA are presented in Fig. 2(a). It can be found that the alloy had a high yield strength $( \sigma _ { \Upsilon } )$ of 559 MPa, high ultimate tensile strength $\big ( \sigma _ { \mathrm { U T S } } \big )$ of $1 0 0 5 \mathrm { M P a }$ , and large room-temperature tensile plasticity of $6 . 2 \%$ . The alloy showed a superb work-hardening ability $\langle \sigma _ { \mathrm { U T S } } -$ $\sigma _ { \mathrm { Y } } { = } 4 4 6 ~ \mathrm { M P a }$ ), which is an effective delay of necking (and failure) and vital for reliability in engineering applications. Therefore, the superb work-hardening capacity accounts for the large ductility. Moreover, the true stress and strain hardening rate $( { \mathrm { d } } \sigma / { \mathrm { d } } \varepsilon )$ against true strain curves are given in the Fig. 2(b). From the $( { \mathrm { d } \sigma } / { \mathrm { d } \varepsilon } ) { - \mathcal { E } }$ curve, it can be found that the $( { \mathrm { d } } \sigma / { \mathrm { d } } \varepsilon )$ first dramatic drop in the range 0 0.009 (stage I), and then slightly decreases in the wide strain range $0 . 0 0 9 \substack { - 0 . 0 5 8 }$ (stage II), finally, sharply falls until tensile failure over the strain of 0.058 (stage III). A similar three-stage work hardening described above is observed both in some HEAs [24,27] and steels [28].  In order to understand the excellent mechanical properties of the $\mathsf { A l } _ { 0 . 9 } \mathsf { C o F e N i } _ { 2 }$ EHEA, the fracture surface was observed by SEM (as shown in Fig. 2(c) and (d)). From Fig. 2(c), the fracture surface is mainly composed of the ductility tear edge and elongated groove microstructure, which is similar to the $\mathsf { A l C o C r F e N i } _ { 2 . 1 }$ EHEA [25]. By connecting the FCC $\left( \operatorname { L } 1 _ { 2 } \right)$ and ordered BCC (B2) composite structure in the $\mathsf { A l } _ { 0 . 9 } \mathsf { C o F e N i } _ { 2 }$ EHEA, the formation mechanism of these trench-like microstructures can be concluded as follows. During the tensile deformation, the soft FCC phase is stretched, which leads to the FCC $\left( \operatorname { L } 1 _ { 2 } \right)$ phase becoming thinner and the edge protruding. Meanwhile, the hard B2 phase with bare deformation was separated from the soft FCC $\left( \operatorname { L } 1 _ { 2 } \right)$ phase at the bottom of the groove, which leads to the formation of this slender groove structure. It is suggested that the elongated groove microstructure making much energy was absorbed during ductile failure, which plays significant roles on the fracture toughness.  In order to further analyze the fracture model of the alloy, the high magnification SEM image of the fracture surfaces is shown in Fig. 2(d). There are some small holes on the fracture surface (marked with red arrows). Some of the holes were produced during the casting process of the alloy. The others were caused by the plasticity mismatch between the FCC $\left( \mathrm { L } 1 _ { 2 } \right) ,$ ) and B2 phases in the alloy. In these critical interfaces, voids prefer to nucleate, accumulate and then grow into micro-cracks. Several micro-cracks found in the present EHEA should be classified as follows. One was the crack nucleated at the end of the B2 phase and then propagated (marked with red solid lines), in a certain direction. This trend is similar to the fracture mechanism of the B2 phase in the $\mathsf { A l C o C r F e N i } _ { 2 . 1 }$ EHEA [29]. Another was the crack nucleated at the boundaries of FCC $\left( \operatorname { L } 1 _ { 2 } \right)$ and B2 phases and then propagated (marked with a red box) in the direction of $4 5 ^ { \circ }$ . The B2 phase was broken into several parts by the crack resulting in an early shear fracture of the B2 phase. With the increase of the strain, the deformation inconsistency of FCC $\left( \operatorname { L } 1 _ { 2 } \right)$ and B2 phases increased, resulting in the two-phase separation at the phase interface. Thus, the cracks at the FCC $\left( \operatorname { L } 1 _ { 2 } \right)$ and B2 phase boundaries will lead to an ultimate fracture. Moreover, the river pattern appears in the B2 phase (shown in the blue circle), which indicates that the fracture mechanism of the B2 phase is of a brittle type. In summary, the coupling growth of soft FCC and hard B2 phases contributed to the excellent mechanical properties of the $\mathsf { A l } _ { 0 . 9 } \mathsf { C o F e N i } _ { 2 }$ EHEA.

- Linked text (the paper's own sentences, as linked by the PDF parser): The dynamic evolution of deformation substructures at different strains with TEM (Figs. 3–5) were carefully investigated to decipher the deformation characteristics of FCC $\left( \operatorname { L } 1 _ { 2 } \right)$ and B2 phases in the $\mathsf { A l } _ { 0 . 9 } \mathsf { C o F e N i } _ { 2 }$ EHEA. At an initial deformation of $0 . 6 \%$ , a number of dislocations occur in the soft FCC $\left( \mathrm { L } 1 _ { 2 } \right)$ phase, while no obvious dislocations are observed in the hard/brittle B2 phase (see Fig. 3(a)). This feature indicated that dislocation movement is more active in the FCC $\left( \operatorname { L } 1 _ { 2 } \right)$ phase than that in the B2 phase. As presented in Fig. 3(b), the FCC $\left( \operatorname { L } 1 _ { 2 } \right)$ phase exhibited obvious planar deformation characteristics, such as the dislocation planar slip and dislocation outcrop (marked with a red circle). Furthermore, stacking dislocations are also seen along the interface of FCC $( \mathrm { L } 1 _ { 2 } ) / \mathrm { B } 2$ phases, which is due to the large internal stress caused by the lattice mismatch between FCC $\left( \operatorname { L } 1 _ { 2 } \right)$ and B2 phases. In order to release this internal stress, dislocations pile up at the interface. The block-up of dislocations at the FCC $( \mathrm { L } 1 _ { 2 } ) / \mathrm { B } 2$ phase boundaries provides the EHEA with the high yield strength. It can be seen that in the initial deformation stage, dislocation slip fist occurs in the soft FCC $\left( \operatorname { L } 1 _ { 2 } \right)$ phase, indicating that the dislocation planar slip in the FCC $( \mathrm { L } 1 _ { 2 } )$ ) phase contributed to the deformation of the early stage of the $\mathsf { A l } _ { 0 . 9 } \mathsf { C o F e N i } _ { 2 }$ EHEA.

- Linked text (the paper's own sentences, as linked by the PDF parser): As the deformation amount increases to ${ \sim } 1 . 5 \%$ , still no obvious dislocation are observed in the hard/brittle B2 phase, while the dislocations density is significantly increased in the FCC $\left( \operatorname { L } 1 _ { 2 } \right)$ phase (shown in Fig. 4(a)). Meanwhile, some planar dislocation configurations, for instance, dislocation slip band (shown in Fig. 4(b)), dislocation build-up (presented in Fig. 4(c)), dislocation intersection (exhibited in Fig. 4(d)) dislocation networks (represented in Fig. 4(e)) are observed in the FCC $\left( \operatorname { L } 1 _ { 2 } \right)$ phase. These configurations appear only when two or more coplanar slip systems act in one grain and are usually found in some low-SFE FCC metals, indicating that the cross slip is quite difficult [28,30]. With the increase of the plastic strain, the dislocation in FCC phase is hardened and the dislocation gradually accumulates. Hence, it is necessary for the greater stress to promote the dislocation to continue to move. In order to adapt to the increase of the stress, the following two phenomena may occur in the FCC phase, one is to cause a more slip system to start, and the other is that the deformation of the alloy extends to other regions, which leads to the formation of slip bands. It is illustrated that the above complex dislocation morphology appears in the FCC $\left( \operatorname { L } 1 _ { 2 } \right)$ phase is beneficial to adapt to the increase of the stress.

- path: /home/aid1/Documents/causalmat/matmech/Journal_of_Materials_Science_&_Technology/j.jmst.2020.05.053/images/e7ecc981e25c088d2757eb235637ebd22cd9a98f987f9a638d2e76ec1c10dd17.jpg
- caption: Fig. 5. TEM micrographs of the $\mathsf { A l } _ { 0 . 9 } \mathsf { C o F e N i } _ { 2 }$ alloy after tensile fracture: (a) dislocations configurations in the FCC $\left( \mathrm { L } 1 _ { 2 } \right)$ ) phase; (b) dislocations configurations in the B2 phase
- Linked text (the paper's own sentences, as linked by the PDF parser): With the further deformation to fracture for the $\mathsf { A l } _ { 0 . 9 } \mathsf { C o F e N i } _ { 2 }$ EHEA, a fast dislocation multiplication takes place in both FCC $( \mathrm { L } 1 _ { 2 }$ ) and B2 phases. The density of dislocations is higher in the FCC $\left( \operatorname { L } 1 _ { 2 } \right)$ phase than in the B2 phase at this deformation level. As shown in Fig. 5(a), the FCC $\left( \operatorname { L } 1 _ { 2 } \right)$ phase exhibits a dense dislocation network arrangement formed by typical Taylor lattices, in which the parallel dislocation configuration is called the dislocation wall. The formation of high dense dislocation walls is mainly attributed to the increasing stress concentration, thus improving the tensile strength of the $\mathsf { A l } _ { 0 . 9 } \mathsf { C o F e N i } _ { 2 }$ EHEA. Moreover, the interaction of different slip systems in the dislocation wall also improves the strain hardening ability, delays the occurrence of necking, and increases the plasticity of the $\mathsf { A l } _ { 0 . 9 } \mathsf { C o F e N i } _ { 2 }$ EHEA. At the same time, grain boundaries are known to constitute strong obstacles to the dislocation motion, resulting in the formation of dislocation pile-ups (denoted by the arrow in Fig. 5(a)). With the increase of deformation, the dislocation density at the two FCC $\left( \operatorname { L } 1 _ { 2 } \right)$ and B2 phases boundaries increases, resulting in the increased internal stress. When the internal stress reaches the yield strength of the B2 phase, the B2 phase will begin to experience plastic deformation. Thus, the straight and parallel dislocation morphology can be seen in the B2 phase at this deformation level, as shown in Fig. 5(b). Moreover, it can also be seen that the dislocation is transferred from the interface to the B2 phase, and the stress concentration of FCC $( \mathrm { L } 1 _ { 2 } ) / \mathrm { B } 2$ boundaries is released, which makes the alloy experience larger strain. In general, when the deformation reaches fracture, dislocation slip occurred in both FCC $\left( \operatorname { L } 1 _ { 2 } \right)$ and B2 phases, which contributed to the strength and plasticity of the $\mathsf { A l } _ { 0 . 9 } \mathsf { C o F e N i } _ { 2 }$ EHEA.  With increasing the amount of deformation, the main sequence of the sub-structural evolution could be summarized as follows. In the FCC $\left( \operatorname { L } 1 _ { 2 } \right)$ phase, the dislocation changes from planar dislocations to bending dislocation, high-density dislocations, dislocation networks, then to dislocation walls and Taylor lattices. In the B2 phase, the evolution of dislocation is from a very small number of short dislocations to a number of planar dislocations.  For the $\mathsf { A l } _ { 0 . 9 } \mathsf { C o F e N i } _ { 2 }$ EHEA, the three-stage work hardening characteristics can be explained by the sub-structural evolution during tensile deformation. In stage I, there existed a deformation delay in the B2 phase, while the FCC $\left( \operatorname { L } 1 _ { 2 } \right)$ phase controlled the deformation of the alloy. And obvious planar deformation characteristics is observed in the FCC $\left( \operatorname { L 1 } _ { 2 } \right)$ phase. In stage II, the larger deformation occurred in the FCC $\left( \operatorname { L } 1 _ { 2 } \right)$ phase, resulting the significantly increase of dislocations density and formation of different dislocation configurations, such as dislocation slip band, dislocation build-up, dislocation intersection, dislocation networks. The formed above complex dislocation configurations in the FCC $\left( \operatorname { L } 1 _ { 2 } \right)$ phase required higher stress to move further. Moreover, the increased dislocations density indicated the FCC $\left( \mathrm { L } 1 _ { 2 } \right)$ phase underwent a work hardening process at this deformation stage, and then causing the increase in the work hardening rate. In a word, in the stage I and II, the continuously reduced work-hardening rate is due to dislocation-control of plastic deformation processes.  In stage III, straight and parallel dislocation dominates the deformation in the B2 phase, while Taylor lattice and dislocation wall appeared in the FCC $\left( \operatorname { L } 1 _ { 2 } \right)$ phase. The high density dislocation network is difficult to adapt to further strain. Thus, deformation inconsistency of FCC $\left( \operatorname { L } 1 _ { 2 } \right)$ and B2 phases increased, leading to the micro-cracks form along two-phase boundaries, and then propagated resulting in the ultimate fracture. Thus the sharply falls of the work hardening rate could be attributed to the serious strain localization.
