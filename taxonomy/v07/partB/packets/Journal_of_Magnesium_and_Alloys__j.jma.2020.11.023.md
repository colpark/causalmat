- Linked text (the paper's own sentences, as linked by the PDF parser): Undoped $\mathbf { M g } _ { 3 . 2 } \mathbf { B i } _ { 1 . 4 } \mathbf { S b } _ { 0 . 6 }$ is a n-type semiconductor with ultra-high resistivity and low carrier concentration. The temperature dependent Hall carrier concentration $( n _ { \mathrm { H } } )$ and Hall mobility $( \mu _ { \mathrm { H } } )$ of $\mathbf { M g } _ { 3 . 2 } \mathbf { B i } _ { 1 . 4 } \mathbf { S b } _ { 0 . 6 - x } \mathbf { S e } _ { x }$ are presented in Fig. 4a, b, respectively. The room temperature $n _ { \mathrm { H } }$ of Se-doped samples is in the range of $1 . 7 \times 1 0 ^ { 1 9 }$ $\mathrm { c m } ^ { - 3 }$ to $3 . 4 \times 1 0 ^ { 1 9 } ~ \mathrm { c m } ^ { - 3 }$ , comparable with Te-doped samples [11,34–36]. Fig. 4b expresses that temperature-dependent $\mu _ { \mathrm { H } }$ of all the Se-doped samples follows a decreasing trend with the relationship of $\mu _ { \mathrm { H } } \sim T ^ { - p }$ $( 1 \leq p \leq 1 . 5 )$ , implying a dominant charge scattering by acoustic phonons. The mobility starts to drop above $4 5 0 \mathrm { K }$ can be attributed to the increasing vacancy defect concentration caused by the loss of $\mathbf { M g }$ at high temperature. In the temperature range of $3 0 0 { \mathrm { - } } 4 5 0 \mathrm { K }$ , $\mu _ { \mathrm { H } }$ deviated from $T ^ { - 1 }$ to $T ^ { - 0 . 5 }$ due to alloy scattering. The relationships of experimental $n _ { \mathrm { H } }$ and $\boldsymbol { \iota } _ { \mathrm { H } } \ \mathrm { n - M g } _ { 3 } \mathrm { S b } _ { 2 }$ TE materials with different dopants are compared in Fig. 4c, including our results. Moreover, the Hall mobility is also higher than the results reported in the literatures [17,23,34,38]. Undoubtedly, Se is an effective n-type dopant that provides optimum carrier concentration and Hall mobility for $\mathbf { M g } _ { 3 . 2 } \mathbf { B i } _ { 1 . 4 } \mathbf { S b } _ { 0 . 6 }$ , leading to the improved power factor. Pisarenko plots of $s$ versus $n _ { \mathrm { H } }$ are calculated based on Eqs. (1)–(6) using a single parabolic band (SPB) model, assuming the acoustic phonon scattering mechanism (scattering factor $r = - 1 / 2$ ), the results are presented in Fig. 4d [41,42].

- caption: Fig. 5. Temperature dependent (a) resistivity, (b) Seebeck coefficient, (c) power factor (d) total thermal conductivity, (e) electrical thermal conductivity, and (f) lattice thermal conductivity of $\mathbf { M g } _ { 3 . 2 } \mathbf { B i } _ { 1 . 4 } \mathbf { S b } _ { 0 . 6 - x } \mathbf { S e } _ { x }$ samples.
- Linked text (the paper's own sentences, as linked by the PDF parser): As highly-degenerated multi-valley conduction bands were involved in the charge transportation [13,34,43,44], high mobility and carrier concentration will result in low resistivity and low Seebeck coefficients. Fig. 5a,b show the temperature dependent resistivity and Seebeck coefficients, respectively.  Both the resistivity and Seebeck coefficient continuously increase with the increasing temperature, indicating degenerate semiconductor characteristic. With increasing content of Se, the resistivity increases first, and reaches the maximum limit when $x = 0 . 0 1$ . The significant decrease in resistivity can be attributed to the high carrier concentration and mobility. The room-temperature Seebeck coefficient of Se-doped samples ranged between $- 1 7 5 \mu \mathrm { V } \ K ^ { - 1 }$ and $- 2 3 9 \mu \mathrm { V } \ \mathrm { K } ^ { - 1 }$ , which is comparable to the Te-doped samples [13,22]. It is evident from Fig. 5c that over the entire temperature range, the power factor $( P F )$ of $\mathbf { M g } _ { 3 . 2 } \mathbf { B i } _ { 1 . 4 } \mathbf { S b } _ { 0 . 6 - x } \mathbf { S e } _ { x }$ was significantly higher than those of Se-doped samples in the literatures [39,40]. The power factor of the sample with $x = 0 . 0 1$ was $2 9 ~ \mu \mathrm { W }$ $\mathrm { c m } ^ { - 1 } ~ \mathrm { K } ^ { - 2 }$ at room temperature and decreased to $2 2 ~ \mu \mathrm { W }$ $\mathrm { c m } ^ { - 1 } ~ \mathrm { K } ^ { - 2 }$ at $6 2 3 \mathrm { K }$ . Such a high power factor was generated from the high Hall mobility, and $70 \%$ of $\mathbf { M g } _ { 3 } \mathbf { B i } _ { 2 }$ led to the formation of coarse grains, resulting in ultra-low resistivity [18,22,23]. The temperature-dependent total thermal conductivity $( \kappa )$ , electronic thermal conductivity $\left( \kappa _ { \mathrm { e } } \right)$ and lattice thermal conductivity $( \kappa _ { \mathrm { L } } )$ and bipolar thermal conductivity $( \kappa _ { b } )$ of $\mathbf { M g } _ { 3 . 2 } \mathbf { B i } _ { 1 . 4 } \mathbf { S b } _ { 0 . 6 - x } \mathbf { S e } _ { x }$ are presented in Fig. 5d-f. $\kappa _ { \mathrm { e } }$ was estimated according to the Wiedemann–Franz law, $\kappa _ { \mathrm { e } }$ $= L T / \rho$ , where $L$ is the Lorenz number. The Lorenz number was determined by the SPB model assuming acoustic phonon scattering [8,45,46]. $\kappa _ { \mathrm { e } }$ shown in Fig. 5e increased after Se doping, which mainly due to the reduction of resistivity. As shown in Fig. 5f, the sum of the lattice thermal conductivity and bipolar thermal conductivity $\kappa _ { \mathrm { L } } + \kappa _ { b }$ increases with increasing temperature, this may because the bipolar effect occurs at high temperature $\left( > ~ 4 5 0 \mathrm { K } \right)$ in the samples. Looking carefully at our experimental data in Fig. 4a and 4b, the carrier concentration increases while the mobility decreases at high temperature, and the change trend of Seebeck coefficient changes at $4 5 0 \mathrm { K }$ , these phenomena should be related to bipolar effects. $\mathbf { M g } _ { 3 . 2 } \mathbf { B i } _ { 1 . 4 } \mathbf { S b } _ { 0 . 5 9 5 } \mathbf { S e } _ { 0 . 0 1 }$ shows a very low $\kappa _ { \mathrm { L } }$ of $0 . 6 { - } 0 . 7 \mathrm { W } \ \mathrm { m } ^ { - 1 } \ \mathrm { K } ^ { - 1 }$ at low temperature range, yielding a high room temperature thermoelectric performance. The reduction of $\kappa _ { \mathrm { L } }$ can be ascribed to alloy scattering caused by the compositional change in $\mathbf { M g _ { 3 } B i _ { 2 } / M g _ { 3 } S b _ { 2 } }$ alloys [22].
