### F1 [Revealing the influence from Processing to Structure; microscopic=False]
The hollow porous $\mathrm { N i } _ { x } \mathrm { P } _ { \gamma } \mathrm { O } _ { z }$ composite was prepared on the basis of ligand substitution mechanism. The structural representation of the formation of the MOF-derived $\mathrm { N i } _ { x } \mathrm { P } _ { \gamma } \mathrm { O } _ { z }$ is shown in Scheme 1 . The structure of Ni-MOF consists of 1D zigzag chains constructed from two symmetry-inequivalent tetraaqua-nickel (II) units and benzene-1,3,5-tricarboxylic acid (BTC) ligands. These 1D chains can be reinforced and cross linked into a complex network by extensive hydrogen bonding, in which the hydrogen ion of each water molecule is involved in the hydrogen bonding with either carboxylate or water oxygen. [ 13 ] The formation of $\mathrm { N i } _ { x } \mathrm { P } _ { \gamma } \mathrm { O } _ { z }$ involves substitution of BTC ligands with the phosphoric ions, as a result, the derived $\mathrm { N i } _ { x } \mathrm { P } _ { \gamma } \mathrm { O } _ { z }$ forms the 3D framework.

### F4 [Characterizing Structure; microscopic=True]
From the SEM images in Figure 3 a, it can be seen that the as-synthesized pristine Ni-MOF shows a micron-sized rod-like morphology. It is well known that the Ni BTC coordination complex can form 1D polymeric Ni-BTC chains. [ 13 ] The strong $\pi - \pi$ interaction or hydrogen bonding between the ligands could hold the chains together to form 3D network. MOF-derived $\mathrm { N i } _ { x } \mathrm { P } _ { \gamma } \mathrm { O } _ { z }$ inherits the external morphology from the MOF (Figure 3 b) but with two obvious variations. The microrods are much looser with many small pores on the surface. On the other hand, there is an obvious volume expansion of the microrods. This can be ascribed to the substitution effect of the BTC with $\mathrm { P O } _ { 4 } ^ { - }$ units during the hydrothermal synthesis from Ni-MOF precursor. Loosely bound structure is found favorable to enhance the electrochemical performance due to ability to reduce the diffusion length of the ions, increase the uptake of the ions and accommodate large volume change during redox reactions. The energy-dispersive X-ray spectrometry (EDS) analysis of a MOFderived $\mathrm { N i } _ { x } \mathrm { P } _ { \gamma } \mathrm { O } _ { z }$ shows the presence of phosphorous incorporation within the framework (Figure S2, Supporting Information). For conductivity measurements, the active material with carbon black and polyvinylidene difl uoride (PVDF) at the weight ratio of 8:1:1 was mixed with N -methylpyrrolidinone (NMP) to form a homogeneous slurry subsequently drop cast on the glass slide and measured using a four-point probe system. The as obtained resistance values are 1049.42 and $7 1 4 . 1 3 ~ \Omega ~ \mathrm { s q } ^ { - 1 }$ for MOF and MOF-derived $\mathrm { N i } _ { x } \mathrm { P } _ { \gamma } \mathrm { O } _ { z }$ respectively, indicate that the conductivity of MOF-derived $\mathrm { N i _ { x } P _ { y } O _ { z } }$ is better than that of MOF. This improvement in the conductivity can be credited to the substitution of the BTC with $\mathrm { P O } _ { 4 } ^ { - }$ units during the hydrothermal synthesis from Ni-MOF precursor.
