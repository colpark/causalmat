### F1 [Characterizing Structure; microscopic=False]
Figure 1 shows the XRD spectra of the milled powder mixtures and the fabricated RZSZ-0 sample. In the milled powder mixtures, the peaks of $\mathrm { Z r S i } _ { 2 }$ and $\mathrm { B } _ { 4 } \mathrm { C }$ were primarily identified. In addition, trace $Z \mathrm { r } \mathrm { O } _ { 2 }$ and WC were detected simultaneously as shown in Fig. 1(a). The formation of trace $Z \mathrm { r } \mathrm { O } _ { 2 }$ should be attributed to the surface oxidation of the $\mathrm { Z r S i } _ { 2 }$ powders, which may be occurred in the starting powder and handling after the ball-milling. The impurity of WC came from the WC balls which interacted with the $\mathrm { B } _ { 4 } \mathrm { C }$ during high-energy ball-milling because $\mathrm { B } _ { 4 } \mathrm { C }$ is a typical hard material in nature [24].  In the case of the RZSZ-0 composite, $\mathrm { Z r B } _ { 2 }$ and SiC were identified as the dominant crystalline phases and no obvious peaks from the starting materials were detected. The result indicated that Reaction (1) completely finished after the in-situ reactive hot pressing. Trace $Z \mathrm { r } \mathrm { O } _ { 2 }$ phase was still present in the final composites. Furthermore, $\mathrm { W S i } _ { 2 }$ was identified as a new crystalline phase besides the products of Reaction (1). The formation of $\mathrm { W S i } _ { 2 }$ could be associated with the reaction between WC and $\mathrm { Z r S i } _ { 2 }$ as indicated in our previous work [25]. However, it has been outlined that the W-compounds are helpful for the improvement of the oxidation resistance of $\mathrm { Z r B } _ { 2 }$ and $\mathrm { Z r B } _ { 2 } \mathrm { - } \mathrm { S i C }$ composites [26]. 
### F2 [Characterizing Structure; microscopic=False]
Figure 2 shows the XRD spectra of the fabricated composites with different $\mathrm { Z r S i } _ { 2 }$ contents. On the whole, the main consisting phase of the four composites presented no significant difference. The primary crystalline phases were still $\mathrm { Z r B } _ { 2 }$ and SiC, and trace $\mathrm { W S i } _ { 2 }$ and $Z \mathrm { r } \mathrm { O } _ { 2 }$ were also observed. In addition, some weak peaks of ${ \mathrm { Z r S i } } _ { 2 }$ were detected in the final composites attributed to the excessive $\mathrm { Z r S i } _ { 2 }$ introduced as the sintering additive. Among these four composites, the intensity of $\mathrm { W S i } _ { 2 }$ peak increased with increasing quantity of $\mathrm { Z r S i } _ { 2 }$ . Furthermore, $\mathrm { Z r C }$ as a new phase was detected by XRD analysis when the $\mathrm { Z r S i } _ { 2 }$ content was above $2 0 \mathrm { v o l \% }$ . 
### F3 [Others; microscopic=False]
Figure 3 shows the Gibbs free energy of reactions as a function of temperature. From the results of thermodynamic calculations, Reactions (1–3) are feasible at all temperatures. However, the Gibbs free energy of Reaction (1) is much lower than that of Reactions (2) and (3), resulting in the limited $\mathrm { B } _ { 4 } \mathrm { C }$ to react with $\mathrm { Z r C }$ . Therefore, the absence of $Z \mathrm { r } \mathrm { C }$ was observed in the XRD spectra of RZSZ-10 and RZSZ15, while the $Z \mathrm { r } \mathrm { C }$ appeared and the $\mathrm { W S i } _ { 2 }$ intensity increased in XRD spectra of RZSZ-20 and RZSZ-25. 
### F4 [Characterizing Property; microscopic=False]
Figure 4 shows the relative density of the $\mathrm { Z r B } _ { 2 } \mathrm { - } \mathrm { S i C }$ based composites fabricated by the in-situ reactive hot pressing. Without the excessive $\mathrm { Z r S i } _ { 2 }$ as the sintering additive, the final composite RZSZ-0 presented a low relative density of $9 1 . 8 \%$ due to the covalent bonding characters of $\mathrm { Z r B } _ { 2 }$ and SiC. In the case of RZSZ-10 and RZSZ-15, the relative density was $9 4 . 9 \%$ and $9 8 . 5 \%$ , respectively, indicating $\mathrm { Z r S i } _ { 2 }$ could effectively improve the sintering ability of composites during the in-situ reactive hot pressing process. Further increasing the $\mathrm { Z r S i } _ { 2 }$ content, the relative density was $9 7 . 6 \%$ for  RZSZ-20 and $9 6 . 4 \%$ for RZSZ-25, respectively, which slightly decreased in comparison to RZSZ-15 as shown in Fig. 4. Similar result was also indicated in Ref. [28]. In the $\mathrm { Z r B _ { 2 } { - } Z r S i _ { 2 } { - } S i C }$ ternary system, it was found that the high $\mathrm { Z r S i } _ { 2 }$ content would be accompanied by an increase of porosity due to the interaction of $\mathrm { Z r S i } _ { 2 }$ with components of the ceramics [28]. 
### F5 [Characterizing Structure; microscopic=True]
Figure 5 shows the back-scattered electron (BSE) images on the polished surface, which were used to investigate the typical microstructural features of the in-situ reactive hot pressed composites. It can be observed that different phases with different colors dispersed homogeneously in the composites. The main phases were the grey and black phases identified as $\mathrm { Z r B } _ { 2 }$ and SiC, respectively. From the low magnification images of RZSZ-15 and RZSZ-20 shown in Figs. 5(a) and 5(b), a larger amount of elongated $\mathrm { Z r B } _ { 2 }$ grains were observed as the arrows indicated. In addition, some elongated $\mathrm { Z r B } _ { 2 }$ grains interconnected with each other and generated the interlocking microstructures as shown in Fig. 5(c). From the high magnification image of RZSZ-20, it also could be found that the grain size distribution of the $\mathrm { Z r B } _ { 2 }$ was non-uniform. During the sintering process, ductile deformation or even local melting of $\mathrm { Z r S i } _ { 2 }$ particles would occur as Reaction (1) was an exothermic reaction $( \Delta H < 0 )$ . The elongated $\mathrm { Z r B } _ { 2 }$ with multimodal grain distribution would be much easier to slide and interlock under applied pressure thereby promoting the formation of interlocking microstructure. The interlocking microstructures were considered to improve the damage tolerance of the composites. Some insular elongate $\mathrm { Z r B } _ { 2 }$ grains were found in the dark phase which could be produced by the liquid $\mathrm { Z r S i } _ { 2 }$ phase. This eutectic-like microstructure also suggested that local melting occurred during the in-situ reaction process.  The EDS analysis was performed on these samples. EDS analysis in zone A in Fig. 5(a) revealed that the white phase with irregular shape was mainly consisting of $5 9 . 5 3 \mathrm { a t \% }$ Si, $2 1 . 3 8 \mathrm { a t \% }$ W, $1 1 . 4 2 \mathrm { a t \% } \mathrm { C }$ , and $7 . 6 7 \mathrm { a t \% }$ $Z \mathbf { r }$ (Fig. 5(e)). It indicated the white phase could be the coexistence of $\mathrm { W S i } _ { 2 }$ and $\mathrm { Z r C }$ , which were the products of Reaction (2). Furthermore, EDS analysis in zone B in Fig. 5(a) revealed that the dark phase was mainly consisting of $5 8 . 9 1 ~ \mathrm { a t \% } ~ \mathrm { C } , 3 4 . 5 1 ~ \mathrm { a t \% }$ Si, and $6 . 5 8 ~ \mathrm { { a t } \% }$ $Z \mathbf { r }$ (Fig. 5(f)), indicating zone B was the SiC-rich region. The small amount of element $Z \mathbf { r }$ might come from the $\mathrm { Z r S i } _ { 2 }$ and $Z \mathrm { r } \mathrm { C }$ phases. Owing to the ductile deformation of $\mathrm { Z r S i } _ { 2 }$ at high temperature, some $Z \mathrm { r } \mathrm { C }$ particles could be carried by $\mathrm { Z r S i } _ { 2 }$ to the SiC-rich region under the applied pressure during the reactive hot pressing.  Figures 5(a)–5(d) show that the quantity of excessive $\mathrm { Z r S i } _ { 2 }$ had a significant influence on the grain size evolution of $\mathrm { Z r B } _ { 2 }$ . For RZSZ-15 and RZSZ-20, these elongated $\mathrm { Z r B } _ { 2 }$ grains presented a length of $0 . 5 { - } 2 ~ \mu \mathrm { m }$ approximately with a submicron width. While, $\mathrm { Z r B } _ { 2 }$ grain coarsening was observed and some large $\mathrm { Z r B } _ { 2 }$ grains appeared as shown in zone C in Fig. 5(d). It was concluded that increasing the quantity of excessive $\mathrm { Z r S i } _ { 2 }$ would result in grain growth of $\mathrm { Z r B } _ { 2 }$ . The grain coarsening could be attributed to the high atom diffusion ability along the grain boundaries due to the occurrence of more liquid phase. However, significant anisotropy growth of $\mathrm { Z r B } _ { 2 }$ grains occurred in all the fabricated composites. 
### F6 [Characterizing Structure; microscopic=True]
Figure 6 shows the SEM image of the fracture surface of RZSZ-15. It could be seen that the anisotropic growth of $\mathrm { Z r B } _ { 2 }$ grains was evident and nearly all the $\mathrm { Z r B } _ { 2 }$ grains developed into the platelet morphology. Moreover, a large number of nano-sized SiC particles were formed among the $\mathrm { Z r B } _ { 2 }$ grains. The grain size of  SiC has a strong influence on the mechanical properties of $\mathrm { Z r B } _ { 2 } \mathrm { - } \mathrm { S i C }$ composites. Fine grain size of SiC would result in high mechanical properties, while huge SiC grains in the composites acted as the critical flaws for the failure of $\mathrm { Z r B } _ { 2 } \mathrm { - } \mathrm { S i C }$ composites [29].  It is known that $\mathrm { Z r B } _ { 2 }$ has a hexagonal crystal structure which could be promoted to present the anisotropic grain growth similar as $\mathrm { S i } _ { 3 } \mathrm { N } _ { 4 }$ . The fastest growing planes of $\mathrm { Z r B } _ { 2 }$ are the $\{ 0 1 0 \} , \{ 1 1 0 \}$ families. The low-activation energy diffusion path is along ${ \mathrm { < } } 2 1 0 { \mathrm { > } }$ and ${ < } 1 1 0 { > }$ directions, that lead to the $\mathrm { Z r B } _ { 2 }$ grains tending to grow along $c$ -axis perpendicular to the basal plane [30]. It was also indicated that the formation of $\mathrm { Z r B } _ { 2 }$ platelets was strongly related to the liquid phase and plastic flow mechanism [20,31]. In the present work, the liquid phases might be from two sources. One was the oxide impurities such as $\mathrm { S i O } _ { 2 }$ and ${ \bf B } _ { 2 } { \bf O } _ { 3 }$ appeared on the surface of the raw powders. The other was the melt of $\mathrm { Z r S i } _ { 2 }$ at the local region due to the exothermic Reaction (1). Under the applied pressure, the $Z \mathbf { r }$ and B atoms in the liquid phase would easily transport to the low surface energy planes of $\mathrm { Z r B } _ { 2 }$ grains, which favored in the anisotropic growth of $\mathrm { Z r B } _ { 2 }$ grains resulting to the platelet morphology. 
### F7 [Characterizing Property; microscopic=False]
Figure 7 shows the mechanical properties of the composites. It indicated that the quantity of excessive $\mathrm { Z r S i } _ { 2 }$ had great influence on the mechanical properties of the $\mathrm { Z r B } _ { 2 } \mathrm { - } \mathrm { S i C }$ based composites. With an increase of the $\mathrm { Z r S i } _ { 2 }$ content, the Vickers hardness, flexural strength, and fracture toughness of the composites first increased and then decreased. The relationship of the mechanical properties and the $\mathrm { Z r S i } _ { 2 }$ content is similar to that of the relative densities. However, the RZSZ-20 sample presented the highest Vickers hardness, flexural strength, and fracture toughness, which was $1 7 . 1 \pm$ $0 . 7 \mathrm { G P a }$ , $6 5 5 { \pm } 2 1$ MPa, and $6 . 0 8 { \pm } 0 . 1 7$ $\mathrm { M P a } { \cdot } \mathrm { m } ^ { 1 / 2 }$ , respectively. Furthermore, comparing with RZSZ-20, the Vickers hardness and the flexural strength of RZSZ-25 decreased more obviously, while the fracture toughness of RZSZ-25 decreased slightly. 
### F8 [Revealing the influence from Processing to Property; microscopic=True]
The typical fracture surfaces and the path of crack propagation of the composites after mechanical tests were observed by SEM as shown in Fig. 8. It can be seen that the fracture surfaces of all the samples are rugged. For the RZSZ-0 composite without excessive $\mathrm { Z r S i } _ { 2 }$ , several obvious pores were found on the fracture surface (Fig. 8(a)), in agreement with the relative density data given in Fig. 4. In addition, the formed SiC grains were submicron sized. However, the nano-sized SiC grains were formed in the composites with excessive $\mathrm { Z r S i } _ { 2 }$ . This indicated that the excessive $\mathrm { Z r S i } _ { 2 }$ could refine the SiC grains formed during the in-situ reactive hot pressing. Therefore, in the RZSZ-0, the porous microstructure and the coarse SiC grains might be responsible for the lowest mechanical properties. When excessive $\mathrm { Z r S i } _ { 2 }$ was introduced, only some tiny pores could be observed on the fracture surface of RZSZ-10 (Fig. 8(b)). Typical mixture mode of intergranular and transgranular fracture of $\mathrm { Z r B } _ { 2 }$ platelets presented as the arrows indicated. For the composite RZSZ-15, an obvious self-toughening microstructure of $\mathrm { Z r B } _ { 2 }$ platelets was observed (Fig. 8 (c)). Both intergranular and transgranular fractures were evidenced on the fracture surface, where the larger $\mathrm { Z r B } _ { 2 }$ platelets fractured mainly in a transgranular mode which might be caused by the local stress concentration, whereas the smaller $\mathrm { Z r B } _ { 2 }$ platelets fractured predominantly in the intergranular manner. Particularly, on the fracture surface of RZSZ-20 (Fig. 8(d)), the unique interlocking microstructure formed by amounts of $\mathrm { Z r B } _ { 2 }$ platelets with multimodal grain sizes could be observed. Benefiting from the unique interlocking microstructure, the mechanical properties of RZSZ-20 did not deteriorate with its decreased density. On the contrary, this composite possessed the highest mechanical properties. Figure 8(e) shows the SEM images of RZSZ-25. Significant coarsening of $\mathrm { Z r B } _ { 2 }$ platelets appeared on the fracture surface. Commonly, the coarse grains in ceramics easily become the defect source due to the stress concentration and therefore reduce the flexural strength of the $\mathrm { Z r B } _ { 2 } \mathrm { - } \mathrm { S i C }$ based composites. Due to the coarsening of $\mathrm { Z r B } _ { 2 }$ platelets, the fracture of RZSZ-25 presented in the transgranular mode. Furthermore, some secondary cracks propagated across the nanosized SiC-rich region or along the interface of $\mathrm { Z r B } _ { 2 }$ and SiC grains as shown in Fig. 8(e). The secondary cracks caused by crack branching were shown to be beneficial to the enhancement of fracture toughness of ceramic materials [32]. Therefore, the fracture toughness of RZSZ-25 was as high as $5 . 9 6 { \pm } 0 . 2 3 ~ \mathrm { M P a \cdot m } ^ { 1 / 2 }$ . The improved fracture toughness might be attributed to the self-toughened interlocking microstructure. The in-situ formed interlocking microstructure of $\mathrm { Z r B } _ { 2 }$ platelets provided definite self-toughening effect on the $\mathrm { Z r B } _ { 2 ^ { - } }$ SiC based composites. To achieve a deeper understanding of the toughening mechanism, the path of crack propagation on the polished surface of RZSZ-20 was further inspected by SEM as shown in Fig. 8(f). Benefiting from the effective self-toughening microstructure of the $\mathrm { Z r B } _ { 2 }$ platelets and the nano-sized SiC, it is easy to trigger various toughening mechanisms such as grain pull-out, crack bridging, crack deflection, and crack branching, resulting in the tortuous path and provided additional fracture energy dissipation, thereby resulting in an enhanced fracture toughness.  The self-toughening mechanism is schematically illustrated in Fig. 9. On the crack propagation path, when the initial cracks encountered the inter-locked $\mathrm { Z r B } _ { 2 }$ platelets, they would be stopped by the interlocking structure. With continuously increasing the applied force, the fracture energy would be high enough to break the inter-locked $\mathrm { Z r B } _ { 2 }$ platelets. The collapse of inter-locked structure could significantly reduce the stress intensity on the crack tips.  Simultaneously, the cracks with reduced stress intensity would hardly break the $\mathrm { Z r B } _ { 2 }$ platelets and be preferred to propagate along the grain interface with lower bonding strength. The $\mathrm { Z r B } _ { 2 }$ platelets pull-out was promoted and crack bridging occurred, which gave rise to the longer crack propagation path. When the crack-tip furtherly met the other $\mathrm { Z r B } _ { 2 }$ platelets, the stress intensity was reduced or even blocked. Furthermore, the crack branching caused by SiC rich region was also observed. For $\mathrm { Z r B } _ { 2 } \mathrm { - } \mathrm { S i C }$ composites, because of the mismatch of the coefficient of thermal expansion of $\mathrm { Z r B } _ { 2 }$ and SiC, tension residual stress would be generated in a tangential direction to the $\mathrm { Z r B } _ { 2 }$ matrix around the SiC grains during the cooling down [33]. Hence, the cracks propagated to the SiC-rich region resulting in the crack branching.  (3) The $\mathrm { Z r B } _ { 2 }$ platelets and the formed interlocking microstructure played an important role on the self-toughening mechanism of composites, which were activated by various toughening mechanisms such as grain pull-out, crack bridging, crack deflection, and crack branching, providing the main contribution to the high fracture toughness.
