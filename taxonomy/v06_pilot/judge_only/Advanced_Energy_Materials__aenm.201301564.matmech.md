## Tetrahedron elements
- **Processing**: One-step solvothermal process using graphene oxide, CuCl, and thiourea precursors in alcohol solution, followed by calcination at 350°C in Ar atmosphere
- **Structure**: Hierarchical Cu₂S microspheres wrapped by reduced graphene oxide (RGO) nanosheets; monoclinic Cu₂S phase with nanoflake building blocks; increased surface area and mesoporous structure with RGO content
- **Properties**: Electrocatalytic activity–electrochemical property, charge-transfer resistance–electrochemical property, exchange current density–electrochemical property, power conversion efficiency–photovoltaic property
- **Performance**: Power conversion efficiency of 3.85% in CdS/CdSe quantum-dot sensitized solar cells (QDSSCs) using polysulfide electrolyte, superior to Pt (2.14%) and pristine Cu₂S (3.39%) counter electrodes

### F1 [Characterizing Structure; microscopic=True]
Figure 1 shows scanning electron microscopy (SEM) images of samples prepared by solvothermally reacting $0 . 0 5 \mathrm { ~ M ~ C u C l }$ , $0 . 1 \ \mathrm { ~ M ~ }$ thiourea and $0 . 3 \mathrm { \textrm { g } }$ polyvinylpyrrolidone (PVP) in the alcohol solution with different amounts of graphene oxide (GO) at $1 5 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 1 2 \mathrm { ~ h ~ } }$ . It was observed that the products (defi ned as $\mathrm { C u } _ { 2 } \mathrm { S }$ ) prepared without GO exhibited microsphere structure that had an average diameter of about $2 \ \mu \mathrm { m }$ (Figure 1 a) and was constructed by several nanofl ake building blocks (inset in Figure 1 a). Strikingly, when $5 \textrm { m L }$ GO ethanol solution was added into the synthesis system, the microsphere structure (defi ned as ${ \mathrm { R G O } } { \cdot } { \mathrm { C u } } _ { 2 } { \mathrm { S } } { \cdot } { 1 }$ ) composed of many more and smaller nanofl ake building blocks became very elaborate and resembled a fl ower with a larger average diameter of approximately $3 \ \mu \mathrm { m }$ (inset in Figure 1 b). Particularly, several RGO nanosheets partially and irregularly wrapped the $\mathrm { C u } _ { 2 } \mathrm { S }$ microspheres (marked with red cycles in Figure 1 b). Similarly, as increasing the GO ethanol solution volume to $1 0 \textrm { m L }$ , the average diameter of microspheres (defi ned as $_ { \mathrm { R G O - C u } _ { 2 } \mathrm { S } - 2 }$ ) was up to $4 ~ { \mu \mathrm { m } }$ and the nanofl ake building blocks went into even more and smaller (inset in Figure 1 c). Meanwhile, the $\mathrm { C u } _ { 2 } \mathrm { S }$ microspheres were wrapped by more RGO nanosheets as expected (Figure 1 c). However, with GO ethanol solution up to $2 0 ~ \mathrm { m L }$ , redundant  RGO nanosheets were almost covered with $\mathrm { C u } _ { 2 } \mathrm { S }$ microspheres (Figure 1 d, defi ned as ${ \mathrm { R G O } } { \cdot } { \mathrm { C u } } _ { 2 } { \mathrm { S } } { \cdot } 3 $ ), which became compact and had an average size of around $5 ~ { \mu \mathrm { m } }$ (inset in Figure 1 d). Obviously, the addition of GO signifi cantly infl uenced the solvothermal synthesis and remarkably imparted versatile hierarchical $\mathrm { C u } _ { 2 } \mathrm { S }$ morphologies by varying its amount. More interestingly, RGO- $\mathrm { C u } _ { 2 } \mathrm { S } { - 1 }$ showed several similar features (Figure S1, Supporting Information) of the $\mathrm { C u } _ { 2 } \mathrm { S }$ microsphere structure; $\mathrm { R G O - C u } _ { 2 } \mathrm { S } { \cdot } 2$ (Figure S2, Supporting Information) and $\mathrm { R G O - C u } _ { 2 } \mathrm { S } { \cdot } 3$ (Figure S3, Supporting Information) as well experienced the same phenomenon. It is deduced that the introduction of GO nanosheets may interact with $\mathrm { C u } _ { 2 } \mathrm { S }$ crystal nucleus by their oxygen containing functional groups (e.g., $\mathrm { H - O - C = O } _ { \mathit { i } }$ ) on the nanosheets surface, which consequently had an impact on the growth of $\mathrm { C u } _ { 2 } \mathrm { S }$ nanofl ake building blocks, such as increasing the sites of nucleation for $\mathrm { C u } _ { 2 } \mathrm { S }$ nanocrystals on the surface of GO nanosheets and then reducing the sizes of nanofl akes in the same precursor concentration as that in the reaction without GO nanosheets. 
### F2 [Characterizing Structure; microscopic=True]
Transmission electron microscopy (TEM) measurements were performed to examine the detailed structures of RGO$\mathrm { C u } _ { 2 } \mathrm { S } { - 2 }$ composites. Figure 2 a shows a single microsphere wrapped by some nanosheets around. A close examination revealed that such microsphere was made of thin nanofl akes (Figure 2 b). The nanofl ake was completely crystalline as confi rmed by high-resolution TEM (HRTEM). Lattice fringes with interplanar spacing, $d _ { 5 3 2 } = 0 . 1 9 \ \mathrm { n m }$ can be indexed to monoclinic $\mathrm { C u } _ { 2 } \mathrm { S }$ phase (Figure 2 c). The selected-area electron diffraction (SAED) pattern (Figure 2 d) of the nanofl ake indicated that the nanofl ake was a single crystal and thus the $\mathrm { C u } _ { 2 } \mathrm { S }$ microspheres had good crystallinity.

Figure 3 a shows the X-ray diffraction (XRD) patterns of $\mathrm { C u } _ { 2 } \mathrm { S }$ and RGO- ${ \mathrm { C u } } _ { 2 } { \mathrm { S } }$ samples. Subsequently, the diffraction peaks of the as-synthesized samples can be indexed to $\mathrm { C u } _ { 2 } \mathrm { S }$ (JCPDS No. 33-0490) with observed diffraction peaks at $2 \theta = 2 7 . 2 ^ { \circ }$ , $2 9 . 2 ^ { \circ }$ $3 0 . 9 ^ { \circ }$ , $3 2 . 3 ^ { \circ }$ and $4 7 . 9 ^ { \circ }$ , corresponding well with those of lattice planes (104), (132), (041), (141) and (532) of monoclinic phase (Figure 3 a). [ 45 ] It was noted that the intensities of $\mathrm { C u } _ { 2 } \mathrm { S }$ diffraction peaks were decreased with the increase of RGO amount, mainly due to the covering of RGO nanosheets onto the surface of $\mathrm { C u } _ { 2 } \mathrm { S }$ microspheres (Figure 1 d). On the basis of the thermogravimetric analysis (TGA), the RGO mass ratios of the three ${ \mathrm { R G O - C u } } _ { 2 } { \mathrm { S } }$ composites were 26.8, 41.4, and $5 5 . 3 \%$ , respectively. Compared to $\mathrm { C u } _ { 2 } \mathrm { S }$ , the RGO- $\cdot \mathrm { C u } _ { 2 } \mathrm { S } { - 2 }$ exhibited obvious carbon signal except copper and sulfur elements (Figure S4, Supporting Information), verifi ed by the measurement of energy dispersive X-ray spectroscopy (EDS).  Importantly, the effectiveness of GO reduction in RGO$\mathrm { C u } _ { 2 } \mathrm { S } { - 2 }$ composites was investigated by Fourier transform infrared (FTIR), Raman and XPS measurements. In the FTIR spectrum of GO (Figure 3 c), the strong and broad absorption centered at around $3 4 1 1 ~ \mathrm { c m } ^ { - 1 }$ was assigned to the stretching vibrations of $\mathrm { O - H }$ . The characteristic stretching vibrations of $\mathrm { C } { = } \mathrm { O }$ from COOH $( 1 7 2 6 \ \mathrm { c m ^ { - 1 } } )$ ) groups and C-O (1171 and $1 0 6 8 ~ \mathrm { c m } ^ { - 1 } )$ were clearly observed in GO. [ 42 ] The spectrum also showed the stretching vibration of $\mathrm { C } { = } \mathrm { C }$ at around $1 6 2 8 ~ \mathrm { c m } ^ { - 1 }$ relating to the remaining $\mathrm { s p } ^ { 2 }$ character. [ 47 ] The absorption ascribed to the aromatic C-H deformation was visible at around $8 8 6 ~ \mathrm { {  c m } ^ { - 1 } }$ . [ 48 ] However, for ${ \mathrm { R G O - C u } } _ { 2 } { \mathrm { S } }$ composites prepared via solvothermal process (Figure 3 c), the absorption peak of $\mathrm { O - H }$ group $( 3 4 0 1 ~ \mathrm { c m } ^ { - 1 } )$ reduced dramatically in intensity, and the absorption peaks of C−O $[ 1 1 7 1 \mathrm { c m } ^ { - 1 }$ , $1 0 6 8 ~ \mathrm { c m } ^ { - 1 }$ ), C-H $( 8 8 6 ~ \mathrm { c m ^ { - 1 } } )$ and $\mathrm { C } { = } \mathrm { O }$ from COOH groups $( 1 7 2 6 ~ \mathrm { c m } ^ { - 1 }$ ) substantially disappeared. These results imply that the GO has been reduced to a great extent. [ 42 ]  As expected, the Raman spectra of GO and RGO- $\mathrm { C u } _ { 2 } \mathrm { S } { - 2 }$ composites have two typical peaks at around 1335 and $1 5 8 3 ~ \mathrm { c m } ^ { - 1 }$ (Figure 3 d). That is, the G-band peak at around $1 5 8 3 ~ \mathrm { c m } ^ { - 1 }$ was characteristic of graphitic sheets corresponding to a well defi ned $\mathrm { s p } ^ { 2 } \ \mathrm { C } { \cdot } \mathrm { C }$ structure, whereas, the D-band at around $1 3 3 5 ~ \mathrm { c m } ^ { - 1 }$ came from the existence of defects within the hexagonal graphitic structure. [ 42 ] Thus, a higher $I _ { \mathrm { D } } / I _ { \mathrm { G } }$ peak intensity ratio of a Raman spectrum reveals more defects and disorders of the graphitized structures. In comparison with GO, ${ \tt R G O - C u } _ { 2 } { \tt S }$ composites demonstrated a relative increase in $I _ { \mathrm { D } } / I _ { \mathrm { G } }$ (RGO$\mathrm { C u } _ { 2 } \mathrm { S }$ : 0.99 vs. GO: 0.88), implying considerable disruption of the symmetrical hexagonal graphitic lattice resulting from the reduction reaction and the interaction between $\mathrm { C u } _ { 2 } \mathrm { S }$ microspheres and RGO nanosheets. Meanwhile, for ${ \tt R G O - C u } _ { 2 } { \tt S }$ composites, the peak at $2 7 0 5 ~ \mathrm { c m } ^ { - 1 }$ relating to the existence of the D band, the peak at $2 9 3 3 ~ \mathrm { c m } ^ { - 1 }$ corresponding to the $\mathrm { ~ D ~ + ~ G ~ }$ band and the peak at $3 1 3 6 ~ \mathrm { c m } ^ { - 1 }$ associating with the increased disorder of the symmetrical hexagonal graphitic structure (Figure 3 d), were observed more clearly, which was well correlating with the increase of $I _ { \mathrm { D } } / I _ { \mathrm { G } }$ . In addition, the Cu 2p XPS spectrum of ${ \mathrm { R G O - C u } } _ { 2 } { \mathrm { S } }$ composites shown in Figure 4 c revealed two main peaks loaded at 931.8 and $9 5 1 . 8 \ \mathrm { e V } ,$ corresponding to the Cu $2 \mathsf { p } _ { 3 / 2 }$ and Cu $2 \mathsf { p } _ { 1 / 2 }$ signals, respectively. ### F5 [Revealing the influence from Processing to Performance; microscopic=False]
The $\mathrm { C u } _ { 2 } \mathrm { S }$ microspheres wrapped with different RGO amounts (Figure 1 ), as well as conventional Pt electrode were then exploited as CEs to assemble QDSSCs (Experimental Section). The UV-vis absorption spectra of $\mathrm { T i O } _ { 2 }$ , $\mathrm { T i O } _ { 2 } / \mathrm { C d S }$ and $\mathrm { T i O } _ { 2 } / \mathrm { C d S } / \mathrm { C d S e }$ fi lms are exhibited in Figure S5 (Supporting Information). In comparison with $\mathrm { T i O } _ { 2 }$ and $\mathrm { T i O } _ { 2 } / \mathrm { C d S }$ fi lms, $\mathrm { T i O } _ { 2 }$ /CdS/CdSe fi lms presented a strong response in visible light region and thus were used as photoanodes in QDSSCs (Figure S5c, Supporting Information). The current density-voltage $\left( J - W \right)$ characteristics of typical resulting CdS/CdSe QDSSCs are shown in Figure 5 a, while Table 1 summarizes the photovoltaic parameters of QDSSCs. With the Pt CE-based QDSSC as reference, an enhanced device performance of the QDSSCs organized by utilizing solvothermally prepared $\mathrm { C u } _ { 2 } \mathrm { S }$ microspheres and RGO- ${ \mathrm { . C u } _ { 2 } S }$ composites was clearly observed (Table 1 ). An improved power conversion effi ciency ( PCE ) of $3 . 3 9 \%$ was achieved using $\mathrm { C u } _ { 2 } \mathrm { S }$ CE, compared to $P C E = 2 . 1 4 \%$ using Pt CE. A slightly higher PCE $( 3 . 4 9 \% )$ was obtained for the QDSSC using $\mathrm { R G O - C u } _ { 2 } \mathrm { S } { \cdot } 1$ CE (Table 1 ). Then, the PCE was further increased and the highest PCE was obtained from RGO- ${ \mathrm { C u } } _ { 2 } { \mathrm { S } } { - 2 }$ CE, yielding an open circuit voltage $( V _ { \mathrm { o c } } )$ of 0.556 V, short circuit current density $( J _ { \mathrm { s c } } )$ of $1 5 . 8 5 \mathrm { \ m A \ c m ^ { - 2 } }$ , fi ll factor ( FF ) of 0.44, and PCE of $3 . 8 5 \%$ (Figure 5 a and Table 1 ); this represented an $80 \%$ and $14 \%$ increases in PCEs as compared to the devices prepared by using $\mathrm { P t }$ and $\mathrm { C u } _ { 2 } \mathrm { S }$ CEs, respectively. However, the device prepared by employing $\mathrm { R G O - C u } _ { 2 } \mathrm { S } { \cdot } 3$ CE showed a reduction in $J _ { \mathrm { s c } }$ of $1 4 . 9 2 \mathrm { \ m A } \mathrm { c m } ^ { - 2 }$ , $V _ { \mathrm { o c } }$ of $0 . 5 3 0 \mathrm { V }$ and FF of 0.38, and thus a decreased PCE of $2 . 9 9 \%$ (Table 1 ). Then, three types of CEs, Pt, $\mathrm { C u } _ { 2 } \mathrm { S }$ and RGO- $\mathrm { C u } _ { 2 } \mathrm { S } { - } 2$ CEs were chosen in the following analysis.  As shown in Figure 5 b, the incident photon-to-current effi - ciency (IPCE) spectra as a function of wavelength were measured to scrutinize the different photovoltaic performance of these three CEs. Compared to Pt based QDSSC, the IPCE spectrum over almost the entire wavelength region $( 3 0 0 - 8 0 0 ~ \mathrm { n m } )$ of $\mathrm { C u } _ { 2 } \mathrm { S }$ based QDSSC was higher; however, it was lower than $\mathrm { R G O - C u } _ { 2 } \mathrm { S } { \cdot } 2$ based QDSSC. This result correlated well with the aforementioned current density values of the three QDSSCs (Pt: $1 2 . 9 9 ~ \mathrm { \ m A } ~ \mathrm { c m } ^ { - 2 }$ , $\mathrm { C u } _ { 2 } \mathrm { S }$ : $1 4 . 9 9 ~ \mathrm { \ m A } ~ \mathrm { c m } ^ { - 2 }$ , RGO- $\mathrm { C u } _ { 2 } \mathrm { S } { - 2 }$ $1 5 . 8 5 \mathrm { m A c m } ^ { - 2 }$ , Table 1 ). The improved current density of RGO$\mathrm { C u } _ { 2 } \mathrm { S } { - 2 }$ based QDSSC was mainly attributed to the increased surface area of CE fi lm as above-mentioned in BET analysis and the greater catalytic ability of $\mathrm { R G O - C u _ { 2 } S - 2 }$ CE, which was further confi rmed by the following electrochemical analysis. 
### F6 [Characterizing Property; microscopic=False]
To investigate the electrochemical characteristics of $\mathrm { P t } ,$ , $\mathrm { C u } _ { 2 } \mathrm { S }$ microsphere and RGO- ${ \mathrm { C u } } _ { 2 } { \mathrm { S } }$ composite electrodes in polysulfi de electrolyte, cyclic voltammetry (CV), electrochemical impedance spectroscopy (EIS) and Tafel polarization measurements were carried out. Firstly, CV analysis was performed to study the electrochemical catalytic activities and stabilities of three different electrodes. In the CV plots, the negative currents can be assigned to the reduction of ${ \mathrm { S } } _ { x } ^ { 2 - }$ ions to $\mathrm { S } ^ { 2 - }$ ions while the positive currents are ascribed to the oxidation of $\mathrm { S } ^ { 2 - }$ ions in the polysulfi de electrolyte. For CEs in QDSSCs, the reduction peak currents are most important and largely reveal the catalytic ability of CE for ${ \mathrm { S } } _ { x } ^ { 2 - }$ reduction. [ 24 ] In this regard, the current densities at the reduction peaks of $\mathrm { C u } _ { 2 } \mathrm { S }$ and $\mathrm { R G O - C u _ { 2 } S - 2 }$ electrodes ( Figure 6 a) were remarkably larger than Pt electrode (Figure 6 b), suggesting their much more effi cient catalytic ability for ${ \mathrm { S } } _ { x } ^ { 2 - }$ reduction. Meanwhile, RGO- $\mathrm { . C u } _ { 2 } \mathrm { S } \mathrm { - } 2$ electrode exhibited a slightly higher reduction peak current than $\mathrm { C u } _ { 2 } \mathrm { S }$ electrode. Furthermore, the electrochemical stability of CEs was as well tested by measuring successive CV plots with several cycles. As observed in Figure S6a (Supporting Information), the reduction current of Pt electrode gradually decreased as the cycle increased, which is mainly due to the strong poisoning in polysulfi de electrolyte for Pt fi lm. [ 24 ] However, the $\mathrm { C u } _ { 2 } \mathrm { S }$ electrode also showed poor stability (Figure S6b, Supporting Information). This was largely due to the weak combination between $\mathrm { C u } _ { 2 } \mathrm { S }$ fi lm and fl uorine-doped tin oxide (FTO) substrate observed in the experiment. Thus, the participation of RGO nanosheets greatly enhanced the contact between ${ \mathrm { R G O - C u } } _ { 2 } { \mathrm { S } }$ fi lm and FTO substrate, and ultimately improved its stability (Figure S6c, Supporting Information).  Subsequently, Figure 6 c shows the EIS spectra of symmetric cells with $\mathrm { P t } ,$ , $\mathrm { C u } _ { 2 } \mathrm { S }$ and RGO- $\cdot \mathrm { C u } _ { 2 } \mathrm { S } { - 2 }$ CEs, respectively, where the top inset depicts the corresponding equivalent circuit. The corresponding Nyquist plots of EIS spectra had two semicircles: a small one at high frequency and a large one at low frequency. The high-frequency semicircle can be assigned to the chargetransfer resistance $( R _ { \mathrm { C T 1 } } )$ and interfacial capacitance (CPE1) at the solid-solid interfaces, while the low-frequency one is associated with the charge-transfer resistance $( R _ { \mathrm { C T } 2 } )$ and interfacial capacitance (CPE2) at the CE/electrolyte interface. [ 32 ] The fi tting results of plots using the equivalent circuit were shown in Table S1 (Supporting Information). The $R _ { \mathrm { C T } 2 }$ values were 2103, 9.905, $3 . 3 8 0 ~ \Omega$ for $\mathrm { P t }$ , $\mathrm { C u } _ { 2 } \mathrm { S }$ and ${ \tt R G O - C u } _ { 2 } { \tt S }$ electrodes, respectively. Thus, the huge $R _ { \mathrm { C T } 2 }$ value of Pt CE revealed its poor catalytic activity in polysulfi de electrolyte. ${ \mathrm { R G O - C u } } _ { 2 } { \mathrm { S } }$ electrode gave obviously smaller $R _ { \mathrm { C T } 2 }$ value than $\mathrm { C u } _ { 2 } \mathrm { S }$ electrode, which is mainly because the existence of RGO nanosheets in RGO$\mathrm { C u } _ { 2 } \mathrm { S }$ composite can serve as the framework to tightly hold the $\mathrm { C u } _ { 2 } \mathrm { S }$ microspheres as well as the effi cient channel to transport charges. The good connections of $\mathrm { C u } _ { 2 } \mathrm { S }$ microspheres largely facilitated the electron transport and thus signifi cantly reduced the charge-transfer resistance of the CE fi lm. [ 24,42 ]  To further evaluate the electrocatalytic activity of the three kinds of CEs, Tafel-polarization analysis was performed in symmetric cells that were the same as those used in the EIS measurements. The Tafel polarization curves exhibit the logarithmic current density $( \log J )$ as a function of the voltage ( U ). As showed in Figure 6 d, the exchange current density $\left( J _ { \mathrm { o } } \right)$ can be determined as the intercept of the extrapolated linear region of anodic and cathodic branches when the voltage is zero. The $J _ { \circ }$ also can be evaluated by the equation of $J _ { \mathrm { o } } { = } R T / n F R _ { \mathrm { C T } }$ [ 10,33 ]  Figure 6 d reveals that RGO- ${ \mathrm { C u } } _ { 2 } { \mathrm { S } }$ electrode has the highest $J _ { \circ }$ value and thus the lowest $R _ { \mathrm { C T } }$ with the best electrocatalytic activity, in well agreement with the CV and EIS results.
